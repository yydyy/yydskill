# AI技能库

个人 AI 规则与 skill 的**唯一入口**。`01-工程原则` / `02-个人习惯` 用中文书名做文件夹名；`03-技术栈参考` 的 177 个规则包在 2026-09-26 已全部改成中文名。

原先分散在 `agent-rules-books`、`AI_Cunstom`、`awesome-cursorrules` 的内容已迁到这里。日常只维护本目录。

## 打开就能看懂

| 目录 | 是什么 | 体量 |
| --- | --- | --- |
| `01-工程原则` | 15 本经典书蒸馏成的 skill，每本三份：`SKILL.md` + `完整版.md` + `极简版.md` | 15 个文件夹 |
| `02-个人习惯` | 自己的编码原则、Cocos、框架约束，只有 `SKILL.md` | 5 个文件夹 |
| `03-技术栈参考` | Cursor 社区规则原文（上游 CC0），按需查阅、按需拷贝 | 177 个包 + 18 份精简规则，约 1.34 MB |
| `文档` | 外部工具登记 | 1 个文件 |

每个 skill 文件夹里：

- `SKILL.md`：给 Agent 读的正文（YAML `name` 是英文，Cursor 要求如此）。**这是唯一会被 Cursor 加载的文件。**
- `完整版.md` / `极简版.md`：只有 `01-工程原则` 有，是同一主题的长、短两种长度。
- 注意：`01-工程原则` 的三份正文都是**英文**（书摘原文），`02-个人习惯` 才是中文；想让 agent 稳守代码生成与禁止模式，得去 `完整版.md` 里找 `Code Generation Rules` / `Forbidden Patterns` 两段。

## 怎么用

1. **人看**：进中文文件夹，先读 `SKILL.md`；要深挖再看 `完整版.md`。
2. **Agent 用**：把要用的 skill 文件夹整体复制到 `C:\Users\<你>\.cursor\skills\`（文件夹名保持中文），或复制到具体项目的 `.cursor/rules/`。
3. **技术栈规则**：`03-技术栈参考` 不整体部署——打开 [03-技术栈参考/目录.md](03-技术栈参考/目录.md)，只拷需要的那一个包；整包同步会把上下文撑爆。

## 目录与对照表

- [目录.json](目录.json)：`01` / `02` 共 20 个 skill 的 id、标题、用途对照（手工维护，生成于 2026-09-20）。
- [03-技术栈参考/目录.md](03-技术栈参考/目录.md)：177 个规则包 + 18 份精简规则的中文索引。
- [文档/外部工具登记.md](文档/外部工具登记.md)：在用的外部 skill/MCP（Open Code Review、codeGraph、code-review-graph、mcp-bridge 等）。

## 命名约定

- **`01-工程原则` / `02-个人习惯`**：外层文件夹用**中文书名**，例如 `整洁代码`、`领域驱动设计`。
- **`03-技术栈参考`**：包文件夹用**中文技术栈名**，例如 `React+TS+shadcn·ui 组件开发规范`、`Python FastAPI 规范`。
  - 文件夹名里的 `/` 一律写成 `·`（Windows 不允许 `/`）。
  - 包内 `.mdc` 的**文件名保持英文**——132 个包有多个 `.mdc`，改文件名会牵动太多引用；而且规则生效靠文件里的 `globs` 字段，与文件名无关。
  - `原规则/精简规则/` 是 18 份单文件规则，与 `规则包/` 里对应包是同一份上游 prompt 的中英两版；新项目快速起步时它更省上下文。
- **`SKILL.md` 的 YAML `name`**：必须英文 kebab-case，例如 `clean-code`，不能改成中文。
- 2026-09-26 的目录改名（`rules` → `规则包`、`rules-new` → `精简规则`）已完成，当时的改名脚本已不属于本库；以后再改包名只能手工改，并同步更新 [03-技术栈参考/目录.md](03-技术栈参考/目录.md)。

## 已知现状

- 语言：`01-工程原则` 正文全英文；`03-技术栈参考` 也以英文为主（1037 份 `.mdc` 里约 87% 是纯英文），中文只覆盖包内 `README.md`；只有 `02-个人习惯` 是中文。**中文文件夹名 ≠ 中文规则。**
- 遗留格式 `.cursorrules` 已清零，全库统一 `.mdc`。
- 许可：`01-工程原则` 蒸馏自 agent-rules-books（MIT），`03-技术栈参考` 来自 PatrickJS/awesome-cursorrules（CC0）。两份许可全文原本放在 `文档/`，现已随该目录清理删除，需要时从上游仓库取。

## 不要做的事

- 不要再往旧的三个英文仓库里加规则。
- 不要把 `03-技术栈参考/原规则` 整包同步进项目，会把上下文撑爆。
- 不要改 `C:\Users\<你>\.cursor\skills-cursor\`，那是 Cursor 内置 skill。
