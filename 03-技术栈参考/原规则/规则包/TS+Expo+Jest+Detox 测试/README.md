## 简介
使用本提示的移动应用开发者，可以借助 TypeScript、React Native 和 Expo，创建经过优化、高性能、无障碍且架构健壮的移动应用。

## .cursorrules 提示内容概述
.cursorrules 文件为使用 TypeScript、React Native 和 Expo 进行移动 UI 开发的开发者提供指南。它强调使用函数式编程模式编写简洁、结构良好的 TypeScript 代码，避免使用基于类的组件。涵盖的关键领域包括命名约定、语法、格式化、响应式设计的 UI 样式、性能优化、使用 react-navigation 的导航、状态管理、错误处理，以及使用 Jest 和 Detox 进行测试。文件还涉及安全实践、国际化，以及利用 Expo 的托管工作流进行环境配置、更新和部署。该文件倡导跨 iOS 和 Android 平台兼容性的最佳实践，鼓励开发者遵循 Expo 官方文档。
