## 概要
开发跨平台桌面应用的开发者将受益于使用 Svelte 和 TypeScript 构建安全、高性能、模块化的 Tauri 应用，确保后端通信无缝顺畅。

## .cursorrules 提示词概览
该 .cursorrules 文件为使用 Tauri、Svelte 和 TypeScript 构建桌面应用的开发者提供指导准则。它强调关键原则，如类型安全、响应式 UI 开发、安全、性能优化和测试最佳实践。文件概述了前端开发实践，通过 Axios 实现与后端服务的高效通信，并强制执行 IPC 处理和 HTTPS 使用等安全措施。它还涵盖使用 Vite 的构建与部署策略，以及代码风格和项目结构的约定。依赖包括 Tauri、Svelte、TypeScript、Vite 和 Axios，并强调查阅官方文档以获取最佳实践。
