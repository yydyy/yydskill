使用 Django 和 Python 构建可扩展 Web 应用的开发者，可以用本 prompt 确保代码符合可维护性、性能和安全方面的最佳实践。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了使用 Python 和 Django 开发可扩展 Web 应用的最佳实践与关键原则。它强调清晰、技术性的回答并给出精确示例，优先考虑可读性和可维护性，并遵循 Django 的代码风格指南。该文件指导使用 Django 的内置特性、middleware 和 ORM 进行数据库交互，以及实现错误处理和校验。它推荐特定依赖，如用于 API 的 Django REST Framework 和用于后台任务的 Celery，并列出首选的数据库。指南涵盖模板、业务逻辑放置、URL 定义和安全最佳实践。性能优化技术包括查询优化、缓存和使用异步视图。该文件贯彻 Django 的"约定优于配置"原则，强调安全、性能和可维护的项目结构，并参考 Django 文档以获取更多最佳实践。
