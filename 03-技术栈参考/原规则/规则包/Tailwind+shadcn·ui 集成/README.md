# Tailwind Shadcn UI 集成 .cursorrules 提示词文件

作者：Neeraj Sameer Allu

## 你可以构建什么
TypeScript NextJS 代码片段生成器：一个根据用户输入生成清晰易读的 TypeScript NextJS 代码片段的 Web 工具。用户可以指定组件、功能和所需的 Tailwind CSS 样式，工具会将其转换为完整、开箱即用的代码。NextJS 项目脚手架应用：该应用可生成完整可用的 NextJS 项目设置，包括常用页面、Tailwind CSS 配置以及使用 Shadcn UI 的预样式 UI 组件。用户可以从博客、电商、仪表盘等模板中选择。TypeScript 代码审查机器人：一项面向 VSCode 的服务，分析 TypeScript NextJS 代码，确保其干净、可读并遵循最佳实践。它给出改进建议、捕捉潜在 bug，并确保所有依赖都正确导入。Tailwind CSS 可视化构建器：一个让用户可视化设计组件并导出 Tailwind CSS 代码的 Web 应用。它可与 NextJS 项目集成，提供符合代码可读性和结构最佳实践的生成代码。NextJS 组件库：一个全面的预构建组件库，采用 Shadcn UI 样式，针对 NextJS 项目的性能和可读性优化。每个组件都附带文档和在 NextJS 应用中的用法示例。性能与安全审计工具：一款检查 NextJS 项目性能瓶颈和安全漏洞的应用。它提供详细报告并给出代码修改建议以同时改善两者。交互式 TypeScript 学习平台：一款教育应用，通过交互式教程教授 TypeScript 基础，重点是开发可读、可维护的 NextJS 应用。平台包含测验和实时代码校验。动态表单构建器：一个用于在 NextJS 应用中创建和管理表单的强大工具。该构建器使用 TypeScript 提供稳健的类型检查，并提供用 Tailwind 样式化的现成 Shadcn UI 组件，兼顾功能与美观设计。Shadcn UI 定制服务：一项允许开发者用 Tailwind CSS 定制 Shadcn UI 组件并导出以集成到其 NextJS 项目的 Web 服务，注重输出干净可读的代码。NextJS API 端点生成器：一个用于生成带 TypeScript 的 NextJS API 端点的交互式界面。该工具协助创建结构良好、安全且高性能的端点，确保所有必要的导入和最佳实践都得到遵循。

## .cursorrules 提示词概览
`.cursorrules` 文件作为集成到 VSCode 中的 AI 编程助手的指南，专注于生成干净可读的 TypeScript NextJS 代码。该助手旨在提供周全而准确的支持，强调详细规划、正确性、完整性和可读性。它概述了编写代码的分步方法：先写详细的伪代码，再进入实现。文件强调满足用户要求、彻底验证代码，以及确保所有必要的导入和组件都正确包含在内的重要性。技术栈包括 Tailwind 和 Shadcn UI，所有文件位于 `src` 目录中。
