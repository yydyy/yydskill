## 可以构建什么（What You Can Build）
HTML 与 Tailwind CSS 网页构建器：一个允许用户用拖拽界面设计网页的工具，生成干净的 HTML 和 Tailwind CSS 代码，非常适合希望在不牺牲代码质量的前提下加快设计阶段的开发者。JavaScript 代码助手：一项根据特定功能或算法为开发者建议并生成原生 JavaScript 代码片段的服务，确保代码与时俱进并遵循最新最佳实践。响应式设计检查器：一个让开发者测试网站响应式表现的应用，通过生成 Tailwind CSS 布局并即时反馈改动对不同设备区间的影响。前端代码质量分析器：一个网站工具，分析给定的 HTML、Tailwind CSS 和 JavaScript 代码的可读性、可维护性和性能，给出改进建议。互动学习平台：一项面向开发者的服务，通过聚焦最新趋势和技术的互动编程练习来学习 HTML、Tailwind CSS 和 JavaScript。组件库生成器：一个让开发者用 Tailwind CSS 和原生 JavaScript 创建可复用组件的应用，自动生成并优化所需代码以便纳入任何项目。跨浏览器兼容性检查器：一个帮助开发者的工具，确保其 HTML、CSS 和 JavaScript 代码在不同浏览器中无缝运行，发现不一致时给出针对性的修改和解决方案。Tailwind CSS 定制探索器：一个让开发者探索和试验 Tailwind CSS 配置的应用，生成符合其特定设计需求的代码片段。Bug 检测与修复助手：一项识别 HTML、Tailwind CSS 或 JavaScript 代码中潜在 bug 并给出修复建议或自动修复的服务，确保代码质量与稳定性。前端代码 SEO 优化工具：一个分析 HTML 和 JavaScript 代码是否符合 SEO 最佳实践的网站，为开发者提供可执行的见解，在保持代码干净的同时提升网站的搜索引擎排名。

## .cursorrules 提示文件概述（Overview of .cursorrules prompt）
.cursorrules 文件配置了一个专注于生成 HTML、Tailwind CSS 和原生 JavaScript 代码的 AI 编程助手。该助手在使用最新技术和最佳实践的同时，优先保证代码清晰可读。它提供准确而周到的解决方案，预判用户需求，并确保所有代码无 bug、功能完整。助手以平等专家的身份与用户交流，强调简洁与创新，在提供代码调整时避免不必要的重复。它对任何不确定或知识欠缺之处也保持透明。
