# Go 后端可扩展性 .cursorrules 提示文件

作者：Will Cygan

## 可以构建什么
AI 驱动的 API 建议工具：一个使用 AI 根据指定的项目需求和目标推荐最佳 API 架构和设计模式的应用，聚焦性能、可扩展性和易集成性。自动化数据库优化服务：一项分析数据库 schema 和查询的服务，提供自动化的建议和修改，以提升 SQL 和 NoSQL 数据库的性能与可扩展性。后端安全分析器：一个扫描后端代码和配置中安全漏洞的工具，按照最佳实践提供修复指导。微服务架构蓝图顾问：一个提供详细指南和蓝图的平台，用于构建可扩展、容错的微服务架构，集成最新技术和最佳实践。服务端应用性能剖析器：一个对服务端应用进行性能剖析和可视化的应用，突出瓶颈并给出代码优化建议。实时 CI/CD 流水线生成器：一个根据项目需求和首选云服务提供商自动生成定制 CI/CD 流水线配置的工具，确保高效、安全的部署。全面的缓存策略规划器：一个帮助开发者设计契合其应用架构的高效缓存策略的应用，利用行业最佳实践和 Redis 或 Memcached 等工具。数据基础设施优化仪表板：一个提供数据基础设施优化洞察和建议的仪表板，涵盖 Kafka 和 RabbitMQ 等消息中间件，聚焦吞吐量和延迟。可扩展的负载均衡配置工具：一个指导开发者设置和配置负载均衡器以实现最佳流量分配和可靠性的工具，支持多个云平台。互动式 gRPC 和 Protocol Buffers 工作坊：一个教育平台，提供关于 gRPC 和 Protocol Buffers 的互动教程和工作坊，配有动手实验和真实案例。

## 简介
后端开发者可以利用本提示，在各种云平台和编程语言上实现并优化可扩展、安全、高性能的后端解决方案。

## .cursorrules 提示概览
该 .cursorrules 文件定义了专精后端软件工程的 AI 结对编程助手角色。它概述了助手的专业领域，包括数据库管理、API 开发、服务端编程、性能优化以及各种后端技术与实践。文件规定了 AI 应如何回应用户查询：先分析查询，再提供解释、实用建议、最佳实践，并在相关时给出代码示例。它强调在建议中考虑可扩展性、性能和安全，并以总结关键要点收尾。文件还指导 AI 如何处理不清晰的查询以及超出后端范围的查询。
