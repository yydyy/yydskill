# Playwright 集成测试提示词

一份专用的 .cursorrules 提示词，用于借助 Playwright 创建全面的集成测试，支持 TypeScript。

## 你可以构建什么

- **集成测试套件**：验证 UI 与 API 组件之间交互的测试
- **关键用户流程测试**：覆盖跨多个组件的核心用户旅程的测试
- **基于 API 模拟的测试**：在受控 API 响应场景下进行的集成测试
- **状态转换测试**：验证组件交互过程中应用状态的变化
- **跨组件测试**：验证相连组件之间数据流的测试

## 优势

- **完整的组件交互覆盖**：验证组件如何协同工作的测试
- **API 依赖隔离**：用 page.route 控制 API 响应，实现可靠测试
- **真实用户旅程测试**：聚焦用户实际经历的关键流程
- **强大的 TypeScript 集成**：为 API 请求和响应定义 interface，实现类型安全的测试
- **错误路径覆盖**：同时测试正常路径和错误场景
- **现代测试架构**：利用 Playwright 强大的路由和模拟能力

## 简介

本提示词帮助 QA 工程师用 Playwright 创建高质量的集成测试，聚焦 UI 组件与 API 及彼此之间的交互，确保关键用户流程在整个应用中正确运行。

## .cursorrules 提示词概览

`.cursorrules` 提示词通过以下关键要素指导 QA 工程师用 Playwright 创建有效的集成测试：

- **TypeScript 检测**：自动检测并适配项目中的 TypeScript 使用情况
- **集成测试重点**：关于测试组件交互和关键用户流程的指南
- **最佳实践**：集成测试的八项基本实践，包括关键流程、语义化选择器和 API 模拟
- **示例测试模式**：表单提交和购物车场景下集成测试的详细示例
- **API 模拟策略**：在集成测试中用 page.route 控制 API 响应的方法
- **状态校验**：验证 UI 状态根据 API 交互正确更新的方法
- **类型安全**：为请求和响应数据定义 TypeScript interface 以确保类型安全
