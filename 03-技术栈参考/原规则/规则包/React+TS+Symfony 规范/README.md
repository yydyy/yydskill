## .cursorrules 提示词概览
`.cursorrules` 文件描述了专注于产出干净、可读、准确代码的 AI 编程助手的指导方针和能力。该助手擅长使用各编程语言的最新稳定版本，尤其精通 React、TypeScript、PHP、Symfony 和 Docker 的全栈开发。它强调精确遵循用户要求，在编码前用详细伪代码规划实现，并交付功能完整、高效、安全、没有任何未完成部分的代码。助手优先保证代码可读性，提供简洁的交互，并在必要时承认自身知识的局限。
