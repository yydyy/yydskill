## 你可以构建什么
Supabase 认证管理器：让开发者轻松搭建和定制 Supabase 认证流程的工具，提供拖拽式配置邮箱/密码和 OAuth 集成，可监控和管理用户的认证状态，并提供登录模式分析。基于 NextUI 的 UI 主题生成器：帮助开发者为其 NextUI 项目设计并导出主题化组件的在线平台，可自定义颜色、排版和组件样式并实时预览。Next.js 应用脚手架服务：生成开箱即用、内置 Supabase 集成的 Next.js 应用，预置认证、仪表盘和导航组件的默认页面。Iconify 图标管理器：让开发者搜索、自定义和管理 Iconify 图标的 Web 应用，提供调整尺寸、颜色的工具，并可无缝集成到 TypeScript 和 React 应用中。React 仪表盘模板构建器：使用 NextUI 组件创建可定制 React 仪表盘模板的工具，与 Supabase 后端服务顺畅集成，内含数据可视化和用户管理的预置组件。面向 TypeScript 应用的落地页创建器：面向开发者的专用页面构建器，用 TypeScript 和 React 技术栈快速创建并部署落地页，提供模板选择、联系表单和用户注册组件。认证流程测试工具：测试和验证集成 Supabase 的 Web 应用认证流程的应用，提供登录、注册和邮箱确认流程的模拟。Supabase 数据库可视化工具：可视化和管理 Supabase 数据库的在线界面，提供查询、schema 浏览和以交互图表呈现的关系映射等功能。响应式 React 导航栏创建器：为 React 应用创建和定制响应式导航栏的简易工具，同时支持移动端和桌面端设计，便于集成到使用 TypeScript 和 NextUI 的项目中。实时错误监控看板：集成到应用中实时监控错误和异常的服务，提供详细报告和易用的看板，便于在 React 应用中调试与处理问题。

## 简介
构建基于 TypeScript 的 Web 应用的开发者可以借助本提示词，使用 React、NextUI、Supabase 和 Next.js 创建带集成认证的结构化解决方案。

## .cursorrules 提示词概述
.cursorrules 文件概述了使用 TypeScript 和 React 构建的 Web 应用的结构与组件，重点涵盖落地页、认证流程和用户仪表盘。它集成 Supabase 提供认证、数据库交互等后端功能。前端使用 NextUI 组件设计，并用 Next.js 实现服务端能力。认证支持邮箱/密码和 GitHub OAuth 登录，逻辑位于指定的 TypeScript 文件中。用户界面包含响应式导航栏、多页面仪表盘中用于导航的可折叠侧边栏，以及错误处理功能。应用图标使用 Iconify。
