作者：Mariano Benedettini

## 你可以构建什么
TypeScript 项目代码审计工具：一项分析 TypeScript 项目的 Web 服务，确保其符合既定指南。它检查命名是否规范、类型使用、函数结构，并遵循 SOLID 原则，同时审查是否符合 NestJS 架构。
NestJS API 骨架生成器：一款根据用户输入生成 NestJS 项目样板结构的应用。它按照提供的指南自动生成模块、控制器、服务并搭建测试框架。
IDE 的 TypeScript 重构插件：一款面向 Visual Studio Code 等主流 IDE 的插件，为 TypeScript 项目提供实时建议和自动重构选项，使其符合既定的编程原则与指南。
NestJS 模块化架构培训平台：一个在线课程平台，提供交互式模块，教授如何按指南在 NestJS 中实现模块化架构，并配有实践项目和测验。
TypeScript 测试套件生成器：一款为 TypeScript 项目自动生成单元测试和验收测试模板的工具，确保遵循 Arrange-Act-Assert 和 Given-When-Then 的 Jest 测试结构约定。
全面的 TypeScript 文档工具：一款为 TypeScript 项目自动生成详细文档的应用，确保使用 JSDoc 注释，并为类和方法使用恰当的命名约定和描述符。
TypeScript 最佳实践知识库：一个围绕 TypeScript 最佳实践提供文章、教程和社区讨论的网站，重点关注整洁代码、设计模式和 NestJS 编程指南。
高级异常处理分析器：一项检查 NestJS 项目的分析服务，确保异常按照指南使用和处理，并给出全局处理器和正确补充上下文的建议。
NestJS 控制器与服务构建器：一个基于 Web 的 GUI 工具，用于在 NestJS 应用中快速生成控制器和服务，包含 DTO、校验和服务契约，并遵循给定的指南。
TypeScript 仓库合规徽章：一项为符合 TypeScript 指南的 GitHub 仓库提供徽章的计划。该工具对公开仓库运行自动检查，通过后授予徽章。

## 简介
使用 TypeScript 和 NestJS 的开发者可以借助这一提示词，遵循最佳实践和设计模式，编写整洁、可维护、文档完善的代码。

## .cursorrules 提示文件概述
`.cursorrules` 文件提供了一套全面的 TypeScript 编程指南与最佳实践，重点聚焦 NestJS 框架。它包含 TypeScript 通用使用原则，如强制类型声明、避免函数内空行，以及为不同代码组件遵守特定命名约定。文件还概述了编写整洁高效函数、以不可变方式管理数据、在类中遵循 SOLID 原则的推荐做法。此外，它给出了基于异常的错误处理、结构化测试实践的指导，以及使用 NestJS 构建应用的特定架构原则，包括模块化架构和 API 封装。文件还包含使用 Jest 的测试建议，强调对控制器、服务和 API 模块进行单元测试、验收测试和端到端测试。
