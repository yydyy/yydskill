# TypeScript LLM 技术栈 .cursorrules 提示文件

作者：Raphael Mansuy

## 你可以构建什么
多供应商 LLM 集成平台：一项在线服务，让开发者无缝集成并管理多个 LLM 供应商。它提供统一的 API，可在不同供应商间轻松切换，确保充分利用各类 LLM 特性。TypeScript 函数式工具库：一个全面的库，提供工具函数、类型别名与泛型，增强 TypeScript 中的函数式编程。它倡导不可变性与可组合性，让编写干净、可维护的代码变得更容易。错误处理与日志框架：一个专为增强 TypeScript 应用错误处理与日志能力而设计的框架。它内置自定义错误类型，并提供装饰器以便轻松集成到现有代码库。异步工作流管理工具：一款旨在用 async/await 模式简化异步操作管理的工具。它提供重试逻辑、超时管理与竞态条件检测等高级功能。开发者友好 API 库：一个聚焦于通过直观、高度可组合的 API 打造愉悦开发体验的库。它包含 HTTP 请求、数据校验、文件操作等常见任务的模块。类型安全 YAML 编辑器：一款让用户以类型安全方式编辑 YAML 文件的应用，借助 js-yaml 与 TypeScript 严格类型系统的能力，防止配置文件中的常见错误。MIME 类型管理服务：一项提供高级 MIME 类型检测与映射功能的 Web 服务，借助 mime-types 库增强 Web 应用中的文件处理与内容协商。UUID 管理与生成应用：一款提供 UUID 生成与管理高级功能的应用，利用 uuid 库确保分布式系统中标识符的唯一性。Zod 模式仓库：一个托管可复用 zod schema 的平台，覆盖常见数据校验用例，让开发者可以共享并获取经过验证与测试的 schema，加速应用开发。TypeScript 文档生成器：一款利用 JSDoc 注释与 README 文件、自动生成 TypeScript 项目全面文档（含示例与最新信息）的工具。

## 简介
开发者可借助本提示创建结构良好的 TypeScript 代码库，用于多供应商 LLM 架构，具备完善的文档、类型安全与高效的异步操作。

## .cursorrules 提示文件概述
.cursorrules 文件为精通大语言模型（LLM）多供应商架构与 TypeScript 函数式编程的软件工程师与产品经理概述指南与最佳实践。它强调编码标准，包括命名约定、文件组织与代码风格，倡导使用类型别名与泛型等 TypeScript 特性。文件强调单一职责原则、依赖注入、错误处理与全面单元测试的重要性，还突出了使用 JSDoc 的文档实践，以及有效运用特定库（如 axios、js-yaml、mime-types、node-gyp、uuid 与 zod）来增强功能性与可维护性。
