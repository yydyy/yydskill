# Cursor AI WordPress 草稿 macOS .cursorrules 提示文件

作者：Shaun Andrews

## 你可以构建什么
WordPress 草稿管理器：一款增强型管理工具，扩展了 PressThat 的功能，让用户无需登录 WordPress 站点即可直接在系统托盘应用中编辑、发布或删除草稿文章。多站点 WordPress 集成：PressThat 的一个版本，面向管理多个 WordPress 站点的用户，提供应用内切换站点的能力，并在单一界面中管理所有站点的草稿。PressThat 分析：一个扩展，提供草稿文章的分析数据，包括字数统计、预计阅读时长与草稿积压提醒，让用户了解草稿已挂起多久。协作与分享工具：一项让用户直接从应用与团队成员分享草稿的功能，通过评论与建议在发布前进行协作与收集反馈。跨平台同步：开发一款在多设备间同步草稿数据的应用，确保在一台设备上查看或修改的草稿会反映到连接同一用户账户的所有设备上。草稿提醒与通知服务：用户可为草稿工作设置提醒，或收到关于在设定时间内未更新草稿的通知。可定制草稿仪表板：一项允许用户自定义草稿文章仪表板显示方式的功能，提供不同的视图模式、筛选与排序选项，便于更好的组织管理。AI 内容建议：一项由 AI 驱动的功能，分析草稿并基于 SEO 最佳实践、可读性与互动策略提出改进建议。离线编辑模式：允许用户在应用内离线继续处理草稿，网络连接恢复后自动同步更改。与其他博客平台集成：扩展功能以支持 Blogger、Medium 或 Ghost 等其他博客平台的草稿管理，为所有博客需求提供统一的仪表板。

## 简介
构建 WordPress 管理工具的开发者可利用本提示，创建一款通过系统托盘查看与管理 WordPress 草稿文章的桌面应用。

## .cursorrules 提示文件概述
.cursorrules 文件概述了一个名为 PressThat 的项目：一款与 WordPress 网站交互、用于管理草稿文章的系统托盘应用。该应用需要配置用户的 WordPress 网站 URL、用户名，以及从 WordPress 后台获取的 Application Password。用户体验包括下载、安装并打开应用，输入网站凭据，测试连接并同步草稿文章。菜单栏或系统托盘图标会显示草稿文章数量，点击图标即呈现主界面，结合卡片与表格展示草稿，并按时间由近及远排列。
