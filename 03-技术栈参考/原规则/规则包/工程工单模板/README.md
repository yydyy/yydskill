# 工程工单模板提示词（Engineering Ticket Template Prompt）

一个专用的 .cursorrules 提示词，用于创建包含详细需求、实现计划和验收标准的标准化工程工单，助力开发团队高效协作。

## 可以构建什么（What You Can Build）

- **结构化工单**：适用于任何任务管理系统的标准化、完整工程工单
- **实现路线图**：清晰、分步的功能实现指南
- **验收标准**：以列表或 BDD 格式给出的明确成功标准
- **技术规格**：详细的技术背景与约束
- **Sprint 规划辅助**：故事点估算与迭代分配建议

## 优势（Benefits）

- **需求清晰**：结构化格式清楚传达需要构建什么
- **技术背景**：帮助工程师理解任务的背景信息
- **实现指导**：给出建议但不过度规定方案
- **Sprint 规划**：工作量估算，支撑敏捷规划流程
- **跨团队对齐**：衔接产品、工程与 QA 视角的格式
- **减少歧义**：最大限度减少澄清提问的完整模板

## 简介（Synopsis）

本提示词帮助技术产品经理创建标准化、完整的工程工单，为开发者提供理解、实现和测试新功能所需的全部信息，从而高效推进开发。

## .cursorrules 提示文件概述（Overview of .cursorrules Prompt）

.cursorrules 提示词引导用户创建高效的工程工单，具备以下关键要素：

- **灵活的格式**：同时支持列表式和 Given-When-Then 式验收标准
- **完整的章节**：涵盖工程工单所有核心组成部分的完整模板
- **详细示例**：两个采用不同格式的完整示例
- **最佳实践**：编写高效工程工单的十条关键原则
- **适配建议**：针对不同工具和团队定制工单的建议
- **平衡把握**：在提供足够细节的同时保留技术上的发挥空间
