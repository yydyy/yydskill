## 简介
使用 Elixir 和 Phoenix 的开发者可以利用本提示改进提交文档，通过纳入健壮的约定式提交（conventional commit）策略和发人深省的追问，确保全面的代码审查。

## .cursorrules 提示内容概述
.cursorrules 文件为参与软件开发流程的 Elixir 专家定义了指南和规则，涉及 Elixir、Phoenix、Docker、PostgreSQL 等特定技术。它包含在实现前先考虑所有需求的代码编写方法。此外，它提供了约定式提交信息的结构化格式，详述特定类型、可选作用域、描述、正文内容和脚注，以确保代码文档和版本控制的清晰与一致。文件还建议对以 "VV" 为前缀的询问给出简洁回答，并建议在提供解决方案后提出发人深省的追问。
