## .cursorrules 提示词概览
`.cursorrules` 文件为在使用 Node.js、React、Vite、TanStack Query、TanStack Router 和 Tailwind 等技术的项目中编写 TypeScript 代码提供指导方针和约束。它强调维护现有代码和格式，偏好函数式和声明式编程模式，并使用描述性变量名。文件概述了组件的文件结构，提倡使用 TypeScript interface 而非 type，并主张使用函数式组件。它还规定使用 Tailwind 进行样式设计，并鼓励高效数据处理和渲染策略等性能优化。文件强制执行特定的命名约定和语法规则，以确保代码库的一致性和可维护性。
