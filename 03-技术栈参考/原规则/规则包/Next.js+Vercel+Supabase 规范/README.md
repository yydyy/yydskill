# Next.js + Vercel + Supabase .cursorrules 提示词文件

作者：JackFinnegan

## 你可以构建什么
BA Copilot AI 聊天机器人：专为业务分析师创建和迭代 BPMN 图而设计的 AI 驱动聊天机器人。它利用自然语言理解用户提问，提供智能的图表建议与修改。BPMN 可视化与编辑平台：用户可上传各种格式的 BPMN 图、进行可视化并使用 bpmn-js 等工具实时编辑的 Web 应用。基于文档的 BPMN 增强服务：分析上传的文档（如员工手册或政策指南），识别业务流程图中缺失的环节或改进点，为用户提供 AI 生成建议的服务。带社区分享的协作 BPMN 工具：业务分析师分享 BPMN 图、获取社区反馈并应用集体智慧改进业务流程的在线平台。BA 资源与工具箱库：面向业务分析师的综合资源中心，提供适配各种 BA 任务的模板、工具和指南，并可轻松融入 BPMN 流程图工作流。AI 驱动的 BA 职业顾问：根据业务分析师的个人资料和行业趋势，提供职业建议、技能发展资源和招聘信息的数字助手。需求与流程图生成器：把用户输入转化为需求和流程图的应用，实现书面需求与可视化流程表达之间的自动转换。安全的 BA 数据保险库：面向业务分析师的安全文档管理系统，可存储、整理和访问关键资源，同时确保数据隐私。BA 交互历史分析工具：利用交互历史识别模式、提出改进建议并洞察过往 BPMN 流程的工具。BA 虚拟社交社区：供业务分析师拓展人脉、围绕最佳实践展开讨论、分享知识并协作应对挑战的在线平台。

## 优势
集成式 AI 建议系统利用上传的文档增强 BPMN 图，促进直观的迭代式开发与流程修改。层级化布局的全面 UI 支持 BA 专属任务，包括图表创建、交互式编辑、文档撰写和社区互动。量身定制的技术指导基于 Next.js 和 Vercel AI，可按开发者水平推荐工具，并保持项目文件夹层级结构的完整性。

## 简介
本提示词适合为业务分析师构建 AI 驱动 BPMN 图工具的开发者，帮助其借助 Next.js、Supabase、Vercel AI 和 Tanstack Query 创建 Web 平台。

## .cursorrules 提示词概述
.cursorrules 文件描述了 'BA Copilot' 的开发，这是一款旨在辅助业务分析师的工具。这个最小可行产品（MVP）的核心功能是一个 AI 聊天机器人，能够通过与用户交互并基于上传的文档给出建议，来创建和修改 BPMN 图。UI 包含输入提问、上传流程图和文档、查看 AI 生成建议等区域。此外，BA Copilot 更宏大的愿景是打造一个面向业务分析师的综合平台，具备工具箱、社区讨论和招聘板等特性，通过网络效应和传播实现增长。技术栈主要涉及 Next.js、Vercel AI 和 Supabase，以 React 为基础，并使用 Devias 模板搭建项目结构。总体目标是交付一个高效、易用、面向业务分析任务的工具。
