# SwiftUI 开发指南 .cursorrules 提示文件（SwiftUI guidelines .cursorrules prompt file）

作者：kevin regenrek

## 可以构建什么（What You Can Build）
SwiftUI 起步套件：一个拥有清晰 SwiftUI 架构、采用最新 SwiftUI 组件的项目模板，帮助开发者快速启动新项目。SwiftUI 设计指南：一个提供遵循最新 SwiftUI 设计规则的现成代码片段和示例的应用，帮助开发者打造视觉精美、响应式的 UI。SwiftUI 组件库：一组基于最佳实践的可复用 SwiftUI 组件和修饰符集合，聚焦可维护、干净的代码与最新更新。SwiftUI 动画实验室：一个试验 SwiftUI 动画能力的互动工具，让开发者用最新特性创建并预览动画。SwiftUI 布局构建器：一个可视化应用，帮助开发者用 VStack、HStack、ZStack 和 GeometryReader 设计响应式 SwiftUI 界面，紧跟 SwiftUI 的最新更新。SwiftUI 本地化管理器：一项管理本地化文件的服务，聚焦 SwiftUI 项目，用简洁的界面按最新标准添加和编辑不同语言的字符串。SwiftUI 网络请求模板：一个在 SwiftUI 中进行网络编程的起步模板，采用最新最佳实践，包括结合 async/await 与 URLSession 发起网络请求。SwiftUI 数据持久化工具包：一套 SwiftUI 应用数据持久化的最佳实践和现成方案，包括遵循最新指南的 CoreData 集成。SwiftUI 手势探索器：一个让开发者互动探索和测试各种 SwiftUI 手势识别器（如滑动和长按）的应用，参考最新的特性。SwiftUI 测试框架：一个为 SwiftUI 项目搭建全面单元测试和 UI 测试提供工具与最佳实践的框架，随最新测试策略同步更新。

## 简介（Synopsis）
iOS 开发者可以使用本提示词，创建架构清晰、可扩展的 SwiftUI 应用，利用最新的 Swift 特性带来高质量的用户体验。

## .cursorrules 提示文件概述（Overview of .cursorrules prompt）
.cursorrules 文件定义了 SwiftUI 项目的结构与设计准则。它勾勒出条理清晰的文件结构，为主文件、视图、视图模型、共享组件、数据模型、服务、工具类、资源和测试分别设置专门的文件夹。设计规则强调使用 SwiftUI 内置组件保持一致的 iOS 外观，掌握布局工具实现响应式设计，添加视觉增强效果，并确保交互性强、引人入胜的用户体验。该文件聚焦使用最新 Swift 和 SwiftUI 版本的特性和文档。
