## .cursorrules 提示内容概述（Overview of .cursorrules prompt）
.cursorrules 文件旨在为 @findhow 包自动化脚本和工作流。它的目标是重构并改造现有的基于 Deno 的自动化脚本，使其用于 @findhow 生态。关键目标包括更新引用、修改脚本以兼容 @findhow、确保配置文件和文档保持最新、维持一致的脚本结构，以及与版本控制、测试和 CI/CD 流水线相集成。这能确保自动化流程与 @findhow 的包结构和规范保持一致，同时借助 Cursor AI 的辅助实现无缝过渡与适配。
