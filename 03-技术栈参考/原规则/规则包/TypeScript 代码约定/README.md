## 概要
使用 Next.js 和 Expo 以 TypeScript 和现代 UI 库构建全栈应用的开发者，遵循这些标准将受益于代码质量的提升和性能优化。

## .cursorrules 提示词概览
该 .cursorrules 文件概述了使用 TypeScript、Node.js、Next.js、Expo 及相关技术开发应用的编码标准和最佳实践。它强调编写简洁、模块化的 TypeScript 代码，同时运用函数式编程模式并避免使用类。文件规定了命名约定、TypeScript 用法指南和语法偏好，以保持代码的一致性和可读性。错误处理被放在优先位置，包括结构化验证、日志记录和用户消息提示。在 UI 方面，文件提倡使用 Shadcn UI、Radix UI、Tailwind CSS 和 NativeWind 进行样式设计，确保以移动优先的方式实现响应式设计。API 调用应通过 tRPC 保证安全，认证由 Clerk 管理。本指南还包含性能优化技术，如动态加载和图片优化，以及针对 Next.js 和 Expo 环境的定制方法，聚焦服务端渲染、数据获取和原生功能利用。建议开发者遵循 Next.js 和 Expo 的相应文档以获取最佳实践。
