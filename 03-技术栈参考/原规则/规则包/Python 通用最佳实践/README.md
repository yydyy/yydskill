## .cursorrules 提示内容概述
.cursorrules 文件规定了开发 Python 项目的指南，重点关注 AI 辅助开发。它强调结构良好的项目——各组件目录分离、模块化设计，以及使用环境变量进行全面的配置管理。该方法包括健壮的错误处理、使用 pytest 进行彻底的测试，以及详细的文档实践。依赖管理通过 uv（首选）和虚拟环境完成，代码风格一致性则使用 Ruff 保证。持续集成与部署（CI/CD）可使用 GitHub Actions 或 GitLab CI 实现。文件倡导 AI 友好的编码实践，如描述性命名、类型提示和富有洞察力的注释，并提供针对这些原则定制的代码片段和说明。此外，它还概述了添加类型注解、描述性 docstring 以及遵循 pytest 测试约定的重要性，确保 Python 开发的清晰与高效。
