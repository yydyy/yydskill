## 可以构建的内容（What You Can Build）
化学方向的 ML 工具包：开发一套全面的软件工具包，提供易用的 API 用于构建、训练和评估面向化学应用的机器学习模型。与 scikit-learn 和 PyTorch 集成，并支持 SMILES、分子指纹等化学表示。自动化超参数优化平台：创建一项服务，使用贝叶斯优化或网格搜索为化学相关的机器学习模型自动调参，帮助研究人员以更少的人工投入获得更好的性能。药物发现平台：设计一个端到端的药物发现解决方案，利用图神经网络等深度学习模型。包含数据预处理、用于交叉验证的骨架拆分（scaffold splits），以及使用 SHAP 等工具的模型可解释性模块。化学数据增强服务：提供一个工具，专门为化学结构应用预定义和自定义的增强策略，帮助模型获得更好的泛化能力，尤其在数据集有限时。交互式化学模型解释工具：开发一个 Web 应用，让用户使用 SHAP 值和积分梯度（integrated gradients）在化学数据集上可视化并解释机器学习预测。化学 ML 性能优化套件：提供一个优化涉及化学数据的机器学习流水线性能的工具，具备性能分析、高效数据结构使用和 GPU 加速支持等功能。机器学习可复现性平台：部署一个基于云的系统，与 MLflow 或 Weights & Biases 等工具集成，用于跟踪实验并确保化学相关机器学习研究的可复现性。化学 ML 流水线单元测试框架：构建一个专用测试框架，包含针对化学数据处理函数和自定义模型组件的预定义测试用例，确保健壮性和可靠性。可视化化学性质预测工具：创建一个应用，使用学到的模型预测并可视化分子性质，并能用 RDKit 工具绘制化学结构。基于 AI 的化学结构转换器：开发一项服务，用机器学习在不同化学表示之间转换（例如从 SMILES 到分子图），具有高准确度。QSAR 模型验证套件：提供一个专用平台，使用时间切分验证（time-split validation）等特定协议验证 QSAR 模型，并提供自动化的统计与假设检验以进行模型评估。

## 简介（Synopsis）
专注化学的数据科学家可以利用 scikit-learn 和 PyTorch，配合高效的数据处理、加工与评估流水线，构建健壮、可扩展的化学分析机器学习模型。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件为使用 Python 开发面向化学应用的机器学习模型提供了详细指南。它概述了关键原则，包括撰写清晰、带示例的技术性回答，确保代码可读性，以及实现高效的数据处理流水线。它规定使用 scikit-learn 处理传统 ML 算法、使用 PyTorch 进行深度学习，并配合 RDKit 和 OpenBabel 等合适的库处理化学数据。该文件讲解了针对化学数据定制的模型开发策略，如超参数调优、集成方法和交叉验证。它涉及基于 PyTorch 的深度学习，强调神经网络设计和性能优化。此外还涵盖了模型评估、可解释性和可复现性等关键方面，以及项目结构、测试和文档的指南。同时概述了依赖项以及代码风格、变量命名和注释的约定。还包括将 ML 模型与 Flask 后端集成以供前端调用的说明，以及对耗时任务使用异步处理的可能性。
