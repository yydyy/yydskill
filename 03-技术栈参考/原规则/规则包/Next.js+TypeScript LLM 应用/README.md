## 你可以构建什么

### 面向学习的交互式编程助手

一款使用指定技术栈的 Web 应用，为新手开发者提供交互式编程课程与练习，集成 LLM 提供实时反馈、讲解与 TypeScript 分步指南。它可以让用户在浏览器中编写代码、获得反馈，并查看实际运行的示例。

### AI 驱动的代码评审工具

开发一个在线平台，开发者可在其上提交代码，借助 LLM 进行 AI 辅助评审。该工具会分析代码库、给出改进建议、检测潜在错误并遵循最佳实践，从而提升代码质量与性能。

### 自动文档生成器

创建一项服务，利用 LLM 从 TypeScript 代码库自动生成全面而清晰的文档，说明每个函数的用途、参数与典型用例。

### AI 驱动的缺陷修复服务

一个平台，开发者可提交带缺陷的代码片段，由 LLM 分析并建议修复方案。与上述前端和后端的集成可确保运行顺畅，直接对 TypeScript 代码提出修改建议。

### 协作式编码环境

使用 Next.js 构建一个实时协作编码平台，允许多位用户编辑同一代码库，并通过 LLM 集成提供实时反馈与建议，如同编码版的 Google Docs。

### 个性化学习路径生成器

一款根据开发者当前技能水平与期望目标提供定制学习路径的应用。它用 LLM 定制课程内容，提供 TypeScript 练习，并辅以 Next.js 中的交互式示例。

### 面向代码优化的 AI 聊天机器人

开发一个集成到 Web 应用中的 LLM 聊天机器人，开发者可粘贴代码片段以获取优化技巧与重构建议，从而提升效率与性能。

### AI 驱动的 UI/UX 改进顾问

一项服务，接收现有 Next.js 项目并用 LLM 建议 UI/UX 改进，借助 Tailwind CSS 强化设计、用 Lucide React 提升图标美感。

### 定制教程生成器

一款根据输入的代码库自动创建教程的工具，用 LLM 针对 Next.js 与 TypeScript 中的特定编程任务或应用功能编写可读的分步指南。

### 智能代码库搜索引擎

实现一个专门面向代码库的搜索引擎，开发者可用自然语言输入查询来定位相关代码片段。它用 LLM 理解查询的意图与上下文，提供准确结果。

## 优势

- 以基于规则的整体方法理解需求，确保代码满足所有项目需求并无缝融入现有技术栈。
- 明确的编码标准优先考虑性能、安全与模块化，同时在详尽与简洁之间保持平衡。
- 强调循序渐进的编码过程，通过 TODO 注释落实责任，实现有条不紊的推进与高质量产出。

## .cursorrules 提示文件概述

.cursorrules 文件概述了一套协助软件开发任务的指南与流程。它强调对技术栈的整体理解，包括前端与后端技术，如 Next.js、TypeScript、Tailwind CSS 以及用于 LLM 集成的 Python。它在编码风格上倡导模块化、DRY 原则、性能与安全。编码过程讲究方法，强调逐步推理与任务优先级排序。文件还包含编辑代码的详细指南、编码详略程度，以及助手的结构化回复格式。助手扮演资深结对程序员的角色，具备所用编程语言的专业能力，并提供需求与代码历史的简明摘要。部署策略尚待确定。
