## 可以构建的内容（What You Can Build）
Ringcon 塔防游戏：使用 Unity 和 C# 开发一款引人入胜的塔防游戏，其独特之处在于以 Nintendo Ringcon 作为控制器。玩家通过 Ringcon 追踪的体能锻炼为炮塔充能，带来创新的游戏体验。Unity 的 Ringcon 集成插件：创建一个简化 Nintendo Ringcon 集成到 Unity 项目的插件，让开发者轻松将体能锻炼映射为游戏动作，实现更多基于健身的游戏体验。健身追踪游戏附加组件：开发一个可与其他 Unity 游戏集成的附加组件，利用 Ringcon 加入健身追踪和基于运动的强化系统，提升各类游戏的互动性。基于运动的游戏机制库：整理一个基于运动的机制库，开发者可将其纳入塔防游戏或其他类型，并为 Unity 提供预置的 Ringcon 支持。Ringcon 游戏开发社区：建立一个在线平台或论坛，供开发者协作创作使用 Ringcon 的游戏，分享代码片段等资源，并在 Unity 技术难题上互相支持。塔防游戏设计课程：提供一门在线课程，专注于在 Unity 中设计和开发塔防游戏，重点是集成 Ringcon 这类非常规控制器，教授游戏机制和稳健的代码架构。基于 Ringcon 的健身应用：开发一个独立的健身应用，用 Ringcon 让锻炼游戏化，把运动变成类似塔防风格的小游戏，通过游戏促进健身。Ringcon 控制的 Game Jam：举办一场 Game Jam，挑战开发者用 Ringcon 创作游戏，鼓励创新，探索以健身为核心机制的全新游戏设计可能性。Unity 重构与代码质量工具：构建一个帮助 Unity 开发者高效重构代码库的工具，提供洞见和建议以提升代码质量，尤其适用于像塔防游戏这类带有非常规输入的复杂项目。虚拟现实健身冒险：创建一款 VR 游戏，将 Ringcon 作为主要输入设备，用塔防机制引导叙事，以体能锻炼推进沉浸式虚拟世界的进程。

## 简介（Synopsis）
正在用 Nintendo Ringcon 控制器重构塔防游戏的游戏开发者，可以借此创建更高效、可维护、可扩展的代码，改善玩法并提升项目的长期可持续性。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件作为使用 Nintendo Ringcon 控制器的塔防类游戏项目的上下文提供者。它概述了项目的当前状态：为长期效率和可扩展性进行重构。开发在 Unity 2021.3.18f1 环境中使用 C#。其目标是让玩家放置炮塔并进行锻炼为其充能，把体育活动与游戏玩法结合在一起。
