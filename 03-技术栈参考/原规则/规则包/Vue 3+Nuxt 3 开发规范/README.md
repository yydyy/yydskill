## 你可以构建什么
Vue 3 组件库：开发一个全面的 Vue 3 组件库，使用 TailwindCSS 进行样式设计，提供按钮、模态框、表单等预置组件。所有组件遵循无障碍最佳实践，并使用 Vue 的 composition API 实现。Nuxt 3 博客平台：使用 Nuxt 3 创建博客平台，允许用户创建、编辑和发布文章。该平台将具备用户身份验证、富文本编辑器，以及使用 TailwindCSS 样式化的可定制模板，并注重 SEO 优化和 markdown 支持。TypeScript-TailwindCSS 起步套件：为新项目构建一个集成 Vue 3、TypeScript 和 TailwindCSS 的起步套件。该套件针对快速开发进行优化，包含 ESLint、Prettier 等必备工具和基础项目脚手架。无障碍 UI 设计系统：使用 Vue 3 和 TailwindCSS 创建一个注重无障碍的设计系统。该系统将包含优先考虑 WCAG 合规性的指南和组件，例如可键盘导航的菜单和对屏幕阅读器友好的元素。JavaScript 转 TypeScript 迁移工具：开发一个工具，帮助开发者在 Vue 3 或 Nuxt 3 环境中将 JavaScript 项目迁移到 TypeScript。该工具将分析 JavaScript 代码并建议 TypeScript 类型和接口，同时确保代码完整性。动态表单构建器：使用 Vue 3 设计一个动态表单构建器应用，让用户通过拖放轻松创建复杂表单。表单可使用 TailwindCSS 样式化，并可导出到其他项目使用，具备完整的校验和提交功能。电子商务平台：使用 Nuxt 3 创建功能齐全的电子商务平台，支持商品列表、用户评论、购物车和支付集成。使用 TailwindCSS 打造简洁的响应式样式，使用 TypeScript 确保整个应用的类型安全。自定义 TailwindCSS 生成器：构建一个 Web 应用，让用户可以定制并生成自己的 TailwindCSS 配置文件。该工具提供滑块和输入项来调整默认 Tailwind 主题，并实时预览更改效果。实时协作工具：使用 Vue 3 和 WebSockets 开发一个实时协作平台，实现即时更新。允许多个用户协同处理文档或代码，具备同步编辑和聊天功能，全部使用 TailwindCSS 样式化。互动学习平台：设计一个使用 Vue 3 和 Nuxt 3 的互动学习平台，提供 Web 开发课程和教程。包含测验、进度跟踪和证书等功能，所有 UI 组件统一使用 TailwindCSS 样式。

## .cursorrules 提示内容概述
.cursorrules 文件概述了专精 Vue 3、Nuxt 3、JavaScript、TypeScript、TailwindCSS、HTML 和 CSS 的高级前端开发者的职责与工作方法。开发者应遵循最佳实践和 DRY（不要重复自己）等原则，提供准确而周全的解决方案。文件强调结构化的工作方式：先用详细伪代码制定计划，确认计划，然后实现完整、无 bug 的代码。文件提供了具体的代码实现指南，例如使用 TailwindCSS 进行样式设计、使用提前返回（early returns）提升可读性，以及变量和函数的命名约定，以增强代码的清晰度和可维护性。文件还鼓励开发者在代码中实现无障碍功能。
