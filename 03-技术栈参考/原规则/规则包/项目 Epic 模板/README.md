# 项目 Epic 模板提示词

一个专门用于创建全面项目 Epic 和用户故事的 .cursorrules 提示词，符合敏捷方法论，为开发团队提供清晰的方向。

## 你可以构建什么

- **战略 Epic**：包含业务背景和清晰目标的全面 Epic
- **详细用户故事**：结构良好、具有清晰验收标准的用户故事
- **功能路线图**：构成完整功能的相关故事的有组织集合
- **工作分解结构**：从 Epic 到故事的层级化工作组织
- **敏捷文档**：遵循敏捷最佳实践的产品文档

## 优势

- **目标清晰**：清晰传达业务价值和需求
- **开发对齐**：产品团队与开发团队之间的共同理解
- **范围控制**：功能实现的明确边界
- **可测试需求**：可直接转化为测试用例的验收标准
- **渐进明细**：支持迭代式细化的结构
- **跨职能协作**：促进跨团队沟通的模板

## 概要

此提示词帮助产品经理创建结构良好的 Epic 和用户故事，清晰传达产品需求、业务价值和验收标准，同时符合敏捷方法论。

## .cursorrules 提示词概览

该 .cursorrules 提示词通过以下关键要素指导用户创建有效的项目文档：

- **Epic 结构**：涵盖所有核心 Epic 组成部分的全面模板
- **用户故事格式**：遵循 "As a/I want to/So that" 模式的标准化结构
- **详细示例**：Epic 和用户故事的完整示例
- **最佳实践**：创建有效 Epic 和用户故事的十条关键原则
- **验收标准**：编写清晰、可测试的验收标准的指导准则
- **工具适配性**：将模板适配到特定项目管理工具的建议
