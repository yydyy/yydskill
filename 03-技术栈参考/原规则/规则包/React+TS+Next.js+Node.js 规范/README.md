## 简介
从事 Next.js 项目的开发者可以使用本提示，构建模块化、类型安全的应用，具备高效的错误处理和优化的组件结构。

## .cursorrules 提示概览
该 .cursorrules 文件为专注于 Solidity、TypeScript、Node.js 和 React 等技术的开发者提供指南。它强调使用准确的 TypeScript 示例编写简洁、技术性强的回复，并倡导函数式与声明式编程风格。核心原则包括：优先模块化而非重复代码、使用描述性变量名、组件优先采用命名导出。文件概述了 JavaScript 和 TypeScript 的具体实践，例如使用 "function" 关键字编写纯函数、利用 TypeScript interface，以及优先考虑错误处理。它规定了 Next.js 14、Wagmi v2 和 Viem v2 等依赖，并就使用 React/Next.js 提供了以函数组件、响应式设计和高效错误管理为核心的指导。此外，它还提供了使用 server actions、数据处理以及维护 Web Vitals 等性能优先事项方面的约定。
