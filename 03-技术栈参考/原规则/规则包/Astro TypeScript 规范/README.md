## 简介
使用 Astro、TypeScript 与 TailwindCSS 的开发者将受益于本提示：建立一致高效的工作流，拥有清晰的提交信息与模块化、可维护的组件。

## .cursorrules 提示文件概述
.cursorrules 文件为在开发环境中保持一致性与最佳实践确立了指南与规则。它包含创建约定式提交信息的具体规则，确保使用 Astro、TypeScript 与 TailwindCSS 的开发遵循规范，并保持一致的代码风格。文件还定义了 "/commit" 等自定义斜杠命令，用于便捷生成符合 conventional commits 规范的 Git 提交信息。这些规则旨在简化开发流程，确保项目内的代码质量与统一性。
