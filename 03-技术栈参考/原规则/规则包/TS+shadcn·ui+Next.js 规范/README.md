作者：Pontus Abrahamsson

## 你可以构建什么
注重 TypeScript 的代码片段生成器 - 创建一个根据用户需求生成简洁、实用的 TypeScript 代码片段的工具。它将融入迭代、模块化和 interface 使用等模式。React 组件设计系统 - 使用函数式 React 组件开发设计系统，集成 Shadcn UI 和 Tailwind CSS，并提供带 TypeScript 接口和声明式 JSX 的示例。错误处理 SDK - 提供一个使用 TypeScript 和 Zod 专注于错误处理和验证的库。它可以对预期错误建模、实现错误边界，并返回用户友好的消息。响应式设计工具包 - 提供一项使用 Tailwind CSS 自动生成移动优先响应式设计的服务，通过图片懒加载和动态组件加载等特性专注于性能优化。Next.js 性能优化器 - 一个分析 Next.js 项目优化机会的工具，聚焦 'use client'、'useEffect'、React Server Components、图片优化和 Web Vitals 改进。Zod 验证工作室 - 创建一个开发者可以用 Zod 设计和测试表单验证的应用，实时获取预期错误模型的反馈以及与函数式组件的集成。搜索参数状态管理器 - 开发一个使用 'nuqs' 管理 URL 搜索参数的实用库，确保 Next.js 应用中的最佳状态持久化。TypeScript 接口转换器 - 一项将 JavaScript 对象和类型转换为 TypeScript 接口的服务，鼓励类型安全以及与函数式编程模式的更好集成。函数式编程练习场 - 一个练习 TypeScript 函数式模式的交互式平台，通过挑战和示例强制模块化并避免使用基于类的组件。Shadcn UI 组件库 - 提供一组使用 Tailwind 和 Radix UI 样式化的预构建 React 组件，针对服务端渲染优化，客户端代码使用降到最低。

## 概要
构建可扩展 React 和 Next.js 应用的前端开发者将受益于实施 TypeScript 驱动的架构，并提升性能、错误处理和 UI 样式标准。

## .cursorrules 提示词概览
该 .cursorrules 文件为编写注重风格、结构和最佳实践的 TypeScript 代码提供指导准则。它强调简洁、函数式和声明式编程，不鼓励使用类和代码重复。建议开发者使用描述性命名约定并系统化组织文件，优先使用 interface 而非 type，并用 map 避免 enum。文件概述了语法偏好，提倡纯函数和简洁的条件判断。错误处理被放在优先位置，建议提前返回、恰当的日志记录和用户友好的消息。在 UI 和样式方面，文件推荐使用 Shadcn UI、Radix 和 Tailwind CSS，强调通过动态加载和 React Server Components 实现响应式设计和性能优化。关键约定包括使用 'nuqs' 管理 URL 状态，以及遵循 Next.js 在数据获取和渲染方面的最佳实践，同时优化 Web Vitals。
