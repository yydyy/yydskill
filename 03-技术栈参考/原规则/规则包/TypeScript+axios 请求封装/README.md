## 可以构建的内容（What You Can Build）
多 LLM 编排平台：创建一个平台，让开发者轻松集成多个大语言模型（如 OpenAI、GPT-3 等）并在它们之间切换。它利用 TypeScript 构建可组合的库，其 API 确保在不同 LLM 提供商之间无缝过渡与编排。TypeScript 函数式编程库：开发一个在 TypeScript 中推广函数式编程范式的库。它包含强调不可变性、纯函数和可组合性的工具函数与辅助函数，帮助开发者编写更易维护、更易测试的代码。动态文档生成器：构建一个工具，使用 JSDoc 注释自动生成全面的 TypeScript 文档。它包含代码示例，并与版本控制系统集成，确保文档始终保持最新。错误处理与日志工具库：创建一个专注于 TypeScript 错误处理的库，支持自定义错误类型和集成日志能力。这对大规模应用或需要健壮的错误跟踪与分析的系统尤其有用。基于 TypeScript 的依赖注入框架：开发一个为 TypeScript 量身定制的轻量、易用的依赖注入框架。该工具提升应用的可测试性和灵活性，聚焦单一职责原则和面向开发者的简洁 API。异步任务管理器：设计一个使用 async/await 模式的 TypeScript 异步任务管理库，提供排队、重试和优雅处理异步操作的工具。类型安全的 YAML 配置管理器：使用 js-yaml 创建一个配置管理工具，让开发者用 TypeScript 中类型安全的 schema 定义并校验配置。它面向需要健壮配置管理方案的应用。MIME 类型检测服务：开发一项利用 mime-types 库的服务，为开发者提供准确 MIME 类型检测和文件扩展名映射的 API。它可作为处理多种文件类型与上传的应用中的重要工具。唯一标识符服务：提供一项围绕 uuid 构建的服务，用于安全地生成和管理唯一标识符。它非常适合需要随机 UUID 进行跟踪、数据索引或安全用途的系统。纯函数分析与优化器：构建一个分析 TypeScript 代码库的工具，识别实现纯函数的机会，并优化现有代码以获得更好的性能和可测试性。它可作为 Web 或 CLI 工具，帮助开发者维护干净高效的代码库。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了专注于大语言模型（LLM）多提供商架构的资深软件工程师与产品经理的编码标准和最佳实践，使用 TypeScript。它提供了命名约定、文件组织和代码风格方面的指南，强调使用 const、箭头函数和 TypeScript 的类型系统。该文件倡导不可变性、可组合性和单一职责原则等理念，以及依赖注入、错误处理、单元测试和使用 async/await 等最佳实践。此外，它规定了 axios、js-yaml、mime-types、node-gyp、uuid 和 zod 等库的有效使用，并强调通过 JSDoc 注释、示例和更新 README 文件来做好文档记录的重要性。
