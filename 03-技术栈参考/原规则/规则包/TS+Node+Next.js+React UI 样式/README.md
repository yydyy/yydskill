## 你可以构建什么
Next.js 学习平台：一个综合学习平台，专注于教授 TypeScript、Node.js、Next.js、React 以及 Shadcn UI、Radix UI、Tailwind CSS 等 UI 框架。它将包含互动教程和练习，巩固文中概述的编码标准和最佳实践。组件库生成器：一个工具，允许开发者按照 Shadcn UI、Radix UI 和 Tailwind 的指南创建和维护组件库。它专注于生成 TypeScript 函数式组件，强调模块化和性能优化。性能优化分析器：一个应用，分析 Next.js 应用的性能问题，并基于最佳实践提供建议，如最小化 'use client'、用 Suspense 包裹组件和优化图片。响应式设计构建器：一个 Web 应用，帮助使用 Tailwind CSS 构建响应式设计，确保设计遵循移动优先方法，并遵循使用 Radix 和 Shadcn UI 组件的原则。TypeScript 接口转换器：一个服务，将现有 JavaScript 代码库转换为 TypeScript，重点是使用接口、函数式组件，并用 map 代替枚举。命名约定检查器：一个工具，强制执行命名约定，包括小写目录名和变量命名标准，确保大型代码库中的一致性。服务端组件转换器：一个服务，帮助在 Next.js 中将客户端组件转换为服务端组件，遵循 SSR 最佳实践，最小化客户端使用并优化 Web Vitals。动态组件加载器：一个库，简化 React 应用中非关键组件的动态加载实现，改善初始加载时间。Next.js URL 状态管理器：一个应用，使用 'nuqs' 管理 URL 查询参数，让在 Next.js 应用中将状态与 URL 同步变得简单高效。图片优化工具箱：一套工具，自动化将图片转换为 WebP 格式、插入尺寸数据和启用懒加载的过程，以获得更好的加载性能。

## .cursorrules 提示内容概述
.cursorrules 文件是面向使用 TypeScript、Node.js、Next.js App Router、React、Shadcn UI、Radix UI 和 Tailwind CSS 的开发者的指南。它强调简洁、技术性强的 TypeScript 编码，提倡函数式和声明式编程模式、模块化以及描述性的变量命名。文件建议使用 TypeScript 接口、以 map 代替枚举，并采用函数式组件。它包含语法和格式化偏好，例如对纯函数使用 "function" 关键字和声明式 JSX。在 UI 和样式方面，它提倡使用 Shadcn UI、Radix 和 Tailwind，并采用响应式设计方法。性能优化建议侧重于最小化客户端 hook、使用 React Server Components、动态加载和图片优化。此外，它还概述了关键约定，如使用 'nuqs' 处理 URL 查询参数、优化 Web Vitals，以及限制客户端组件的使用，并建议在数据获取、渲染和路由方面遵循 Next.js 文档。
