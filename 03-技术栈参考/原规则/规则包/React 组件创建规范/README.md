## 可以构建什么
组件仓库管理器 - 一个帮助开发者轻松搜索、浏览和管理现有 React 组件仓库的应用，集成跨多个项目的复用组件识别功能，并有防止相似组件重复的系统。提示词生成工具 - 一个 Web 应用，通过自动生成新 React 组件的详细提示词来辅助开发者，考虑现有组件、所需 props 和设计规格，同时确保与项目模式保持一致。组件创建助手 - 一项服务，通过分析项目需求、生成清晰的提示词模板，并提供 Tailwind CSS 和 TypeScript 等常用库的集成协助，为创建新 React 组件提供逐步指导。样式与组件 Linter - 一个自动分析代码库中 React 组件的工具，确保它们满足样式和功能要求，并根据项目模式和约定提出改进建议。UI 组件百科 - 一个网站，包含常见 UI 组件及其实现的全面文档，面向使用 React 和 Tailwind CSS 的团队，并提供将组件适配到特定项目结构的最佳实践指南。React 组件共享平台 - 一个以协作为中心的平台，开发者可以共享、审查和协作 React 组件，突出与 TypeScript 和 Tailwind CSS 的兼容性，并提供直接集成到现有项目的选项。动态组件 URL 编码器 - 一个应用，让开发者生成 URL 编码的提示词以分享详细的 React 组件需求，并能将编码后的链接直接集成到项目管理工具和代码仓库中。设计转组件服务 - 一项服务，将设计原型和规格转化为功能完整的 React 组件，包含带类型的 props 和 Tailwind CSS 样式，遵循结构化的提示词创建流程以确保组件输出准确。交互式组件文档工具 - 一个 Web 应用，提供交互式界面来浏览和记录 React 组件，让开发者可直接在文档环境中附加详细提示词、样式说明和集成路径。

## 简介
前端 React 开发者可以使用本提示高效地创建新组件，确保项目内的一致性、TypeScript 的使用和 Tailwind CSS 的合规性。

## .cursorrules 提示概览
该 .cursorrules 文件提供了在项目中创建新 React 组件的结构化方法。它指导开发者首先通过查阅指定目录中的现有组件来评估新组件的必要性。如果需要新组件，它会指导生成详细提示词，重点涵盖命名、用途、props、使用 Tailwind CSS 的样式以及 TypeScript。然后提示词会被 URL 编码并格式化为可点击的链接以进行后续操作。文件还强调让新组件适应现有的项目结构、导入必要的通用组件和应用专属组件、遵循既定模式，并在需要时留有自定义逻辑或状态管理的空间。
