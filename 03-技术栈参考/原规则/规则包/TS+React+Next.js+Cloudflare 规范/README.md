作者：Dhravya Shah

## 你可以构建什么
TypeScript 组件库：使用 TypeScript、Shadcn UI 和 Radix UI 为 React 应用开发组件库，提供完全类型化、可复用且带样式的组件，并通过 Tailwind CSS 进行性能优化。基于 Cloudflare 的博客平台：创建一个无服务器博客平台，利用 Cloudflare 的 D1 数据库存储数据、R2 存储媒体文件、KV 进行缓存。使用 Next.js 和 DrizzleORM 针对速度和服务器端渲染进行优化。高性能电商站点：使用 Next.js 和 Cloudflare 工具开发无头电商平台，聚焦性能优化、WebP 图片加载，并利用 RSC 提供快速、交互式的用户体验。AI 图像仓库：使用 Cloudflare 的 AI 多模态推理和 R2 存储实现 AI 辅助的图像仓库，让用户能够搜索、上传和管理图像，具备高级查询能力并优化图像分发。实时协作工具：使用 Node.js、Tailwind CSS 和 React 构建实时协作 Web 应用，用 nuqs 管理状态，以 Cloudflare KV 作为无服务器后端持久化共享数据，并具备有竞争力的同步速度。Next.js 启动套件：开发一个集成 TypeScript、Radix UI 和 Tailwind CSS 的 Next.js 启动套件，预配置 ESLint、Prettier 并优化响应，助力快速开发高性能 Web 应用。使用 DrizzleORM 的无头 CMS：创建一个无头内容管理系统，用 DrizzleORM 进行数据交互、Cloudflare D1 作为后端、Next.js 作为前端，确保无缝的实时更新和可扩展性。可定制仪表盘：提供一个使用 Shadcn UI 组件的可定制仪表盘模板，支持动态加载、即用型小组件，并用 Tailwind 实现响应式设计，连接 Cloudflare KV 存储用户设置和偏好。服务端渲染新闻门户：用 Next.js 开发新闻门户应用，注重 SSR 以增强 SEO，使用 Tailwind CSS 做样式，并用 Cloudflare 缓存确保内容始终新鲜高效地送达。身份验证微服务：创建一个身份验证微服务，使用 Node.js 和 Cloudflare KV 管理会话，并采用 Radix UI 的定制组件，确保认证流程安全、高性能且可扩展。

## 简介
本提示词适合全栈 JavaScript 开发者，帮助他们使用 Next.js、React、TypeScript 以及 Cloudflare Workers、Tailwind CSS 等现代工具构建可扩展、高性能的 Web 应用。

## .cursorrules 提示词概览
`.cursorrules` 文件概述了一套使用 TypeScript、Node.js 及其他现代 Web 技术（如 Next.js App Router、React 和 Tailwind CSS）进行软件开发的指导方针和最佳实践。它强调熟练使用 Cloudflare 开发者工具，并建议为引入各种 Cloudflare 原语进行相应配置调整。文件提供了代码风格与结构的详细说明，倾向于函数式编程、模块化和描述性命名约定。它提倡使用 TypeScript interface、Shadcn UI、Radix 和 Tailwind CSS 进行 UI 样式设计，并强调诸如减少某些 React hooks 使用、优化图片等性能优化策略。此外，它还给出状态管理和 Web 性能指标优化的约定，同时遵循 Next.js 文档中关于数据获取、渲染和路由的最佳实践。
