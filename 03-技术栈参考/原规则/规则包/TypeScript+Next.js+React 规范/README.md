## 可以构建什么
AI 驱动的电子学习平台：利用 OpenAI API 创建一个互动电子学习平台，提供个性化学习体验。使用 React 组件实现实时测验和作业，Tailwind 实现响应式设计，Firebase 进行用户身份验证和数据存储。实时协作工具：开发一个 Web 应用，让团队在项目上协作并实时共享数据。使用 Deepgram 进行会议音频转录，Firebase 进行用户管理，Vercel AI SDK 提供智能建议功能。图像生成平台：构建一个创意工具，让艺术家使用 Replicate API 的 Stable Diffusion 模型生成图像。用 Tailwind 实现稳健的 UI 带来流畅的用户体验，用 Firebase 存储生成的艺术作品和用户资料。AI 写作助手：使用 OpenAI 创建一个写作助手应用，帮助作者生成内容创意、编辑草稿和完善写作风格。集成 Firebase 保存文档和用户偏好。个性化音频新闻推送：利用 Deepgram 的实时转录把新闻文章转换成音频。用户可以创建自定义新闻播放列表，并借助 Anthropic API 的自然语言处理将其朗读出来。智能健康追踪器：开发一个结合 AI 与存储在 Firebase 中的用户数据来提供健康建议的应用。用户可以与聊天机器人互动获取每日健康提示和提醒，并使用 OpenAI API 的 AI 建议追踪健身目标。AI 驱动的客户支持系统：使用 Anthropic 的对话式 AI 构建一个客户支持平台，对用户咨询提供实时响应。使用 Firebase 存储客户资料和支持工单。虚拟课堂助手：为课堂场景设计一个虚拟助手，使用 Deepgram 实时转录讲座、OpenAI 回答学生问题、Firebase 作为后端支持管理课程表和学生数据。动态电商平台：实现一个带个性化商品推荐的电商网站，使用 Anthropic AI，Firebase 管理库存和客户数据。可用 Tailwind 打造响应式购物体验。互动语言学习应用：创建一个语言学习应用，使用 AI 驱动的聊天机器人与用户进行多语言对话。采用 Deepgram 做语音识别，Firebase 做用户进度跟踪与存储。

## 简介
使用 Next.js、React 和 Tailwind 构建 AI 驱动 Web 应用的开发者，可以利用本模板高效地集成 Firebase、OpenAI、Anthropic、Replicate 和 Deepgram 服务。

## .cursorrules 提示概览
该 .cursorrules 文件概述了使用 TypeScript、Next.js App Router、React 和 Tailwind CSS 的项目结构，重点遵循 Next.js 14 App Router 文档进行数据获取、渲染和路由。该配置在 /src 目录下的模板中包含一组预定义 API，按 API 路由、组件和库等子目录组织。它提供 Firebase、OpenAI、Anthropic、Replicate 和 Deepgram 的配置与工具函数，开箱即用地支持身份验证、数据存储、文本流式传输、图像生成和音频转录。推荐使用 Vercel AI SDK 处理 AI 交互和响应流式传输。
