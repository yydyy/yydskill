## 你可以构建什么
面向学习的交互式编程助手：一个使用指定技术栈的 Web 应用，为新手开发者提供交互式编程课程和练习，集成 LLM 提供实时反馈、讲解和 TypeScript 分步指南。它可以让用户在浏览器中编写代码、获得反馈并查看实际示例。
AI 代码评审工具：开发一个在线平台，开发者可提交代码，借助 LLM 进行 AI 辅助评审。该工具会分析代码库、给出改进建议、发现潜在错误并遵循最佳实践，从而提升代码质量与性能。
自动化文档生成器：创建一项利用 LLM 从 TypeScript 代码库自动生成全面、清晰文档的服务，解释每个函数的用途、参数和典型用例。
AI 驱动的缺陷修复服务：一个平台，开发者可提交带缺陷的代码片段，由 LLM 分析并建议修复方案。按上述方式与前端和后端集成将确保运行顺畅，直接对 TypeScript 代码提出修改建议。
协作式编码环境：使用 Next.js 构建实时协作编码平台，允许多名用户编辑同一代码库，并通过 LLM 集成提供实时反馈和建议，如同编程版的 Google Docs。
个性化学习路径生成器：一款根据开发者当前技能水平和目标提供定制学习路径的应用。它用 LLM 定制课程内容，提供 TypeScript 练习，并辅以 Next.js 的交互式示例。
AI 代码优化聊天机器人：开发一个集成到 Web 应用中的 LLM 聊天机器人，开发者可粘贴代码片段获取优化提示和重构建议，以提升效率与性能。
AI 驱动的 UI/UX 改进顾问：一项接收现有 Next.js 项目、用 LLM 提出 UI/UX 改进建议的服务，利用 Tailwind CSS 增强设计、用 Lucide React 提升图标美观度。
定制教程生成器：一款根据输入的代码库自动生成教程的工具，用 LLM 为 Next.js 和 TypeScript 的特定编程任务或应用功能编写易读的分步指南。
智能代码库搜索引擎：实现一个专门面向代码库的搜索引擎，允许开发者用自然语言输入查询来定位相关代码片段。它用 LLM 理解查询的意图和上下文，提供准确的结果。

## .cursorrules 提示文件概述
`.cursorrules` 文件阐述了一套辅助软件开发任务的指南与流程。它强调全面理解技术栈，包括前端和后端技术，如 Next.js、TypeScript、Tailwind CSS 以及用于 LLM 集成的 Python。它倡导模块化、DRY 原则、性能与安全并重的编码风格。编码过程讲究方法论，注重逐步推理和任务优先级排序。文件还包含详细的代码修改指南、编码详细程度分级，以及结构化的助手回复格式。助手扮演高级结对程序员的角色，具备所用编程语言的专业能力，并提供需求与代码历史的简明总结。部署策略尚待确定。
