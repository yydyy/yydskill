## 你可以构建什么（What You Can Build）
API 性能监控工具：一个使用 FastAPI 追踪、分析和优化 API 性能指标（如响应时间、延迟和吞吐量）的 Web 应用，提供实时仪表板和性能问题告警。异步 API 封装生成器：一个命令行工具，生成基于 FastAPI 的 Python 代码用于对接外部 API。它会自动包含用于非阻塞 API 操作的异步函数和错误处理模式。校验与错误处理库：一个 Python 库，提供工具和装饰器，在 FastAPI 项目中使用 Pydantic 实现一致的错误处理和输入校验，聚焦防护子句、自定义错误类型和错误日志。数据库交互工具：一个轻量级 Python 包，便于在 FastAPI 中配合 SQLAlchemy 2.0 使用异步数据库库，聚焦优化查询性能并使用懒加载技术。FastAPI 中间件套件：一组为 FastAPI 应用预制的中间件，聚焦日志记录、错误监控、性能优化和安全增强。可扩展 API 脚手架服务：一项 Web 服务，允许用户为可扩展的 FastAPI 应用生成样板代码，遵循 API 开发、模块化文件结构和依赖注入模式的最佳实践。Pydantic Schema 生成器：一个 GUI 应用，从 JSON 或 YAML 文件生成 Pydantic 模型和 schema，帮助在 FastAPI 项目中一致地使用输入/输出校验和响应 schema。缓存管理插件：一个 FastAPI 插件，便于集成和管理使用 Redis 等工具的缓存策略，以优化高频访问端点的性能。异步工作流编排器：一个管理 FastAPI 应用中复杂异步工作流和 I/O 密集型任务的工具，提供构建健壮、非阻塞路由的模板和模式。FastAPI 路由优化器：一个 IDE 插件或脚本，审查 FastAPI 代码并针对路由定义、依赖注入用法和异步操作模式提出优化建议，以提升可读性和性能。

## .cursorrules 提示内容概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了使用 Python 和 FastAPI 开发可扩展 API 的关键原则和指南。它强调编写简洁、技术性强的回复并附带准确的代码示例，遵循函数式编程原则，采用模块化和迭代式方法减少代码重复。文件提供了 Python/FastAPI 用法的详细说明，包括文件与函数结构、错误处理和依赖要求。它重点介绍了使用异步操作、缓存和懒加载等性能优化策略。关键约定包括依赖 FastAPI 的依赖注入系统、关注 API 性能指标，以及限制阻塞操作。它鼓励遵循 FastAPI 在数据模型、路径操作和中间件方面的最佳实践。
