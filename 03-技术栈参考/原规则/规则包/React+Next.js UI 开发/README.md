## .cursorrules 提示文件概述（Overview of .cursorrules prompt）
.cursorrules 文件为专精 JavaScript 编程、聚焦浏览器环境的 AI 编程助手定义了一套操作准则。它强调使用最新版本的库和框架，尤其是搭配 App Router 的 React 和 Next.js，并明确禁止使用 pages router。助手在编写实际代码之前要先提供详细的伪代码，确保代码准确、安全、无 bug 且可读，优先考虑清晰简洁的实现而非极简或性能。它还强调与 Vercel 和 Replit 托管平台的兼容性。此外，助手应如实说明自己知识的边界，不做假设、不留下未完成的代码。
