## 你可以构建什么
Vue 性能优化工具包：一款 Web 应用，帮助开发者优化 Vue.js 应用，提供工具分析并改进 Web Vitals（LCP、CLS、FID）等关键性能指标，并基于懒加载、代码分割与图片优化等最佳实践给出建议。TS 转 Vue 代码导出器：一项将遵循最佳实践（如使用 interface、避免 class）的 TypeScript 代码转换为 Vue 函数式组件的服务，与 TypeScript 接口无缝集成，确保可维护性与可扩展性。DaisyUI 与 Tailwind 组件库：一个全面的预置响应式 DaisyUI 与 Tailwind CSS 组件库，可集成到 Vue.js 项目中，包含动态加载选项与移动优先方法的示例。Vue Composition API 教学平台：一个提供教程、示例与最佳实践的教育平台，讲解 Vue Composition API 的 script setup 风格，聚焦函数式编程模式并避免基于 class 的组件。基于 VueUse 的响应式 UI 构建器：一款利用 VueUse 函数在 Vue.js 中创建高性能响应式 UI 的工具。它允许开发者可视化地创建组件并导出，附带懒加载、suspense 包裹等优化性能设置。Vue 项目文件结构整理器：一款 CLI 工具，系统化整理 Vue 项目文件，确保每个文件只包含相关内容，践行 DRY 原则，并用命名约定提升可维护性与清晰度。Vite 构建优化器：一个 Vite 插件，在构建过程中自动实施优化的分包策略（如代码分割），生成更小的打包体积并确保应用快速加载。Vue 图片优化器：一项为 Vue.js 应用处理并优化图片的服务，将其转换为 WebP 格式、添加体积数据并实现懒加载，以改善页面加载时间与性能。Vue 代码建议器：一个浏览器扩展，评审你的 Vue.js 代码的可读性、最佳实践遵循度与性能，提出诸如避免不必要的重渲染、使用描述性变量名等改进建议。Vue 响应式设计检查器：一款在线工具，帮助开发者测试并确保 Vue.js 应用的响应式设计，并就使用 Tailwind CSS 进行移动优先开发给出洞察与建议。

## .cursorrules 提示文件概述
.cursorrules 文件为使用 TypeScript、Node.js、Vite、Vue.js 及相关技术的开发者提供指南。它强调编写简洁、可维护的代码，采用函数式编程模式、避免使用 class 并遵循 DRY 原则。它建议使用 TypeScript 接口、函数优先采用具名导出，并详述目录命名约定。文件概述了使用 DaisyUI 与 Tailwind CSS 的 UI 与样式实践，聚焦响应式设计。性能优化策略包括动态加载、图片优化以及 Vite 构建过程中的分包策略。文件还包含代码评审的最佳实践，强调性能、可读性以及对这些指南的遵守。
