# Xray 测试用例提示

一个专门的 .cursorrules 提示，用于从自动化测试或功能描述创建结构化、兼容 Jira 的 Xray 测试用例。

## 可以构建什么

- **Xray 测试用例**：适用于手动和自动化测试的 Jira 就绪测试场景
- **测试规格说明**：带前置条件和预期结果的清晰、结构化测试用例
- **手动测试说明**：为手动测试人员提供的清晰分步指引
- **数据驱动测试**：带多种数据变体的参数化测试
- **Jira 集成测试**：带正确 Xray 注解以便与 Jira 关联的测试用例

## 优势

- **Jira 集成**：生成可直接导入带 Xray 的 Jira 的测试用例
- **对利益相关者友好**：业务人员也能理解的非技术格式
- **标准化结构**：所有测试用例采用一致的格式
- **自动化兼容性**：创建可用你偏好的框架自动化的测试
- **可追溯性**：包含 Xray 标签，用于把测试关联到 Jira issue
- **完整覆盖**：处理正常流程、边界情况和数据变化

## 简介

本提示帮助 QA 工程师创建格式规范的 Xray 测试用例，可直接导入 Jira，促进技术与非技术利益相关者之间的协作。

## .cursorrules 提示概览

该 .cursorrules 提示指导 QA 工程师创建有效的 Xray 测试用例，包含以下关键要素：

- **结构化格式**：与 Xray 兼容的规范测试用例结构
- **最佳实践**：创建清晰有效测试用例的八项基本实践
- **示例结构**：带前置条件和步骤的完整测试用例详细示例
- **转换流程**：把自动化测试转换为 Xray 格式的分步指南
- **Jira 集成**：使用 Xray 专属注解进行 Jira 关联的指导
- **数据驱动测试**：用多组数据对测试进行参数化的技术
