作者：Dave Bush

## 你可以构建什么
Angular 代码重构工具：一款 Web 应用，开发者可输入现有 Angular 代码并按现代开发标准自动重构，确保符合 ESLint、Prettier、HTMLHint 和 Editorconfig 规则。
Angular 代码质量检查器：一项分析 Angular 代码的在线服务，检查是否符合编码标准，以及性能问题、可读性和可维护性，并提供详细报告和改进建议。
Angular 最佳实践指南：一个全面的 Web 资源，提供以 TypeScript 为重点、最新的 Angular 开发最佳实践，附有示例和讲解，旨在提升代码可读性、性能和可维护性。
交互式 Angular 实训平台：一个为 Angular 开者提供交互式工作坊和练习的平台，用 TypeScript 练习编写整洁、可读的代码，获得实时反馈和专家代码评审。
Angular forNext 工具插件：一款面向主流 IDE 的插件，帮助开发者把传统循环转换为 libs/smart-ngrx/src/common/for-next.function.ts 中的 forNext 函数，提升项目间的一致性。
Angular 代码格式化扩展：一款 VS Code 扩展，按照最新的 ESLint、Prettier、HTMLHint 和 Editorconfig 规则格式化 Angular 代码文件，确保统一的代码风格。
AI 驱动的 Angular 调试助手：一项集成到 IDE 中的服务，专门针对 Angular 项目提供 AI 驱动的调试建议，帮助开发者高效定位和解决问题。
Angular 性能优化服务：一款分析 Angular 应用并建议性能改进的在线工具，聚焦代码效率、资源加载和运行时性能提升。
Angular 代码库文档生成器：一款为 Angular 项目自动生成文档的工具，维护 jsdoc 注释并更新以反映最新的代码库变更，确保可维护性。
Angular 组件库分析器：一款评估自定义 Angular 组件库是否遵循性能、可读性和可维护性最佳实践的应用，提供审计结果和建议改动。

## 简介
希望提升代码质量、遵循最佳实践的 Angular 开发者，可以借助这一提示词，使用最新标准并结合 Jest 测试，构建清晰、可维护、高效的 Angular 应用。

## .cursorrules 提示文件概述
`.cursorrules` 文件规定了使用 TypeScript、Angular 18 和 Jest 的专家级 Angular 程序员的指南，产出清晰、可读、高性能的代码。它强调深思熟虑且准确的推理，聚焦提供论证充分的答案。文件突出最佳实践，如编写无缺陷且功能完整的代码、确保正确的导入和命名，以及遵守来自 .eslintrc.json、.prettierrc 等配置文件的特定编码标准。它还对代码结构和风格设定了约束，包括参数数量、代码行数和嵌套深度的限制。`.cursorrules` 文件鼓励在保留文档、保持简洁的前提下进行重构。
