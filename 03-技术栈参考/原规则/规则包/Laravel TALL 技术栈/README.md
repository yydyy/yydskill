## .cursorrules 提示词概览
该 .cursorrules 文件为使用 TALL 技术栈（包括 Laravel、Livewire、Alpine.js 和 Tailwind CSS）的开发者提供指导和最佳实践。它强调 Laravel、PHP 最佳实践以及注重 SOLID 原则的面向对象编程。重点关注的领域包括使用 PHP 8.1+ 特性、遵循 PSR-12 编码标准、利用 Laravel 的内置功能，以及实现恰当的错误处理和验证。文件还概述了 Livewire 组件、Alpine.js 用法和 Tailwind CSS 样式的最佳实践，以及性能优化和安全措施。鼓励开发者将这些技术无缝集成，确保构建出高效、响应式且美观的 Web 应用。所需依赖包括 Laravel、Livewire、Alpine.js、Tailwind CSS、Luvi UI 组件库，以及用于依赖管理的 Composer。
