# Cypress 端到端测试 .cursorrules 提示文件（Cypress End-to-End Testing .cursorrules prompt file）

作者：Peter M Souza Jr

## 你可以构建什么

端到端测试套件：为 Web 应用创建全面的端到端测试套件，验证登录、注册、结账及其他关键交互等重要用户流程。测试聚焦于验证导航路径、状态更新和错误处理场景，确保应用可靠。
测试自动化框架：使用 Cypress 开发稳健的测试框架，利用 data-testid 选择器、cy.intercept 进行 API mock 和恰当的等待策略等最佳实践。该框架提升测试的可靠性和可维护性，同时减少不稳定测试。
行为驱动测试方案：实现与 BDD 实践一致的测试，从用户视角聚焦应用行为。测试同时验证成功路径和错误场景，全面覆盖应用功能。
TypeScript 增强测试套件：构建能自动检测并适配 TypeScript 项目的测试套件，利用类型安全和增强的 IDE 特性，获得更可靠的测试代码和更好的开发体验。
CI/CD 测试流水线：创建与 CI/CD 流水线无缝集成的测试工作流，对每次构建或部署自动运行测试，快速反馈应用质量。

## 优势

可靠性优先：强调通过恰当的选择器、API mock 和等待策略来减少不稳定，产出稳定、确定性的测试。
TypeScript 自动检测：自动识别 TypeScript 项目并相应调整测试代码语法，无需手动配置即可获得类型安全。
聚焦最佳实践：融入 Cypress 最佳实践，如描述性测试命名、聚焦的测试文件、避免硬编码等待，以提升可维护性。
端到端流程验证：优先测试完整的用户流程而非孤立功能，确保应用从用户视角工作正确。

## 简介

这一提示词赋能 Web 开发者使用 Cypress 为其应用创建可靠、可维护的端到端测试套件，聚焦关键用户流程和行为验证。

## .cursorrules 提示文件概述

`.cursorrules` 文件为使用 Cypress 创建端到端 UI 测试的 QA 工程师和开发者提供指导。它采用 TypeScript 感知的方式，在存在 TypeScript 项目时自动检测并适配。该提示词专注于端到端测试，强调关键用户流程和恰当的测试结构。它推广使用 data-testid 选择器、实现恰当的等待策略、mock 外部依赖，以及创建每个含 3-5 个测试的聚焦测试文件等最佳实践。该提示词包含一个完整的登录测试示例，演示了正确的设置、API mock、交互模式，以及对成功和错误场景的断言。用这一提示词创建的测试会验证导航路径、状态更新和错误处理，确保应用可靠。
