# Cypress 无障碍测试（.cursorrules prompt 文件）

作者：Peter M Souza Jr

## 可以构建的内容（What You Can Build）

无障碍测试套件：创建一套全面的无障碍测试套件，依据 WCAG 标准和最佳实践验证 Web 应用。测试使用 wick-a11y 包自动检测无障碍违规，同时包含针对键盘导航、ARIA 属性和屏幕阅读器兼容性的自定义测试。键盘导航测试：开发系统性验证关键用户流程中键盘导航的测试，确保所有交互元素在不使用鼠标的情况下也能访问，这是运动障碍用户的刚性需求。ARIA 合规性验证：实现验证应用中 ARIA 属性使用是否恰当的测试，确保屏幕阅读器能正确理解 UI 组件的用途和状态。焦点管理测试：构建验证用户交互期间焦点管理的测试，检查焦点是否被正确捕获在模态框中、操作后是否正确恢复，以及是否为键盘用户提供了视觉指示。屏幕阅读器集成测试：创建验证内容是否被正确朗读给屏幕阅读器的测试，特别关注动态内容更新、表单校验消息和交互控件。

## 优点（Benefits）

WCAG 合规性验证：使用 wick-a11y 自动检测违反 Web 内容无障碍指南（WCAG）的情况，帮助应用满足法律和道德上的无障碍要求。TypeScript 自动检测：自动识别 TypeScript 项目并相应调整测试代码语法，无需手动配置即可获得类型安全。组件级测试：支持对单个组件进行无障碍合规性测试，让问题在开发周期中更早被发现。真实用户流程验证：在真实用户流程的语境中测试无障碍，而不是做孤立检查，确保应用真正能被残障人士使用。

## 简介（Synopsis）

本 prompt 让开发者能够使用 Cypress 和 wick-a11y 包创建全面的无障碍测试，验证 WCAG 合规性、键盘导航、ARIA 属性和屏幕阅读器兼容性。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）

.cursorrules 文件为使用 Cypress 创建无障碍测试的 QA 工程师和开发者提供指导。它强调使用 wick-a11y 包验证是否符合 WCAG 标准，以及针对键盘导航、ARIA 属性和屏幕阅读器兼容性的自定义测试。该 prompt 采用感知 TypeScript 的方法，在存在 TypeScript 项目时自动检测并适配。它推广诸如描述性测试命名、按页面或组件分组测试、创建每个包含 3-5 个测试的聚焦测试文件等最佳实践。用本 prompt 创建的测试验证关键的无障碍问题，如键盘导航、正确的 ARIA 属性、颜色对比度和焦点管理。该 prompt 包含一个全面示例，演示自动化无障碍检查、键盘导航测试、ARIA 属性验证和屏幕阅读器兼容性测试。
