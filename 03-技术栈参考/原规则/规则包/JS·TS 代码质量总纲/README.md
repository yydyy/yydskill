# JavaScript TypeScript 代码质量（.cursorrules prompt 文件）

作者：Thomas Haferlach

## 可以构建的内容（What You Can Build）
代码审查平台：创建一个平台，开发者可提交代码进行同行评审，评审基于简单性、可读性和可维护性等最佳实践。该平台可利用 AI 就如何让代码更简洁高效提供自动化建议。重构助手：开发一个 IDE 插件，在编写代码时提供实时反馈，建议符合编码指南（如 DRY 原则、早返回、函数式风格）的重构机会。代码质量分析器：推出一个工具，分析现有代码库对编码指南的遵守情况，识别潜在的改进领域，并生成包含可操作洞见的报告供开发者参考。JSDoc 生成器：创建一个自动化文档工具，从代码生成 JSDoc 注释，确保所有函数都有清晰简洁的描述，帮助更好地理解和维护代码。最佳实践学习平台：提供一个在线学习平台，通过交互式教程和练习教授开发者最佳编码实践，聚焦简单性、可读性、性能和可测试性。Bug 跟踪与修复工具：开发一个工具，不仅跟踪 bug，还分析代码以建议放置 TODO 注释的最佳位置，在代码库出现潜在问题或复杂性时提醒开发者。可复用组件库：创建一个高度可复用、易维护的组件库，遵循函数式、不可变风格等指南，让开发者轻松将这些组件集成到自己的项目中。性能优化服务：推出一项在不牺牲可读性的前提下审查应用性能的服务，提供量身定制的建议以提升 Web 应用的速度和效率。函数排序工具：构建一个工具，依据依赖层级自动组织脚本文件中的函数，保持清晰、合乎逻辑的顺序，便于理解和调试。交互式代码门诊：建立一个在线门诊，开发者可获得资深开发者的一对一指导或研讨会，通过现场编码环节强化干净、可持续的编码实践。

## 优点（Benefits）
10x 开发者人格设定：该 prompt 扮演技艺高超的 10x 开发者角色，提供顶级开发中的高效编码实践洞见。最小代码改动：强调最小化代码更改，避免引入 bug 或增加技术债，突出代码调整中的效率与精确。核心思维聚焦：突出简单性、可读性和可测试性等核心开发原则，确保代码直截了当且易于维护。

## 简介（Synopsis）
本 prompt 让初级开发者受益：它提供一个框架，用于构建干净、可维护、高效的全栈应用，同时提升其编码技能。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了专注于产出高质量、干净、可维护代码的资深全栈开发者的指南。核心思维包括简单性、可读性、性能、可维护性、可测试性和可复用性。编码指南强调诸如使用早返回、描述性命名、以常量代替函数（constants over functions）、函数式与不可变风格等做法。它强调最小化代码更改以避免技术债和 bug，使用 TODO 注释处理 bug，并建议编码前先制定伪代码计划。鼓励使用函数注释和 JSDoc 等规范文档，以及通过函数排序改善代码结构。
