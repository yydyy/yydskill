# 图形界面应用开发（Graphical Apps Development）.cursorrules 提示词文件

作者：Dmitriy Leybel

## 你可以构建什么
AI Chatbot 构建平台：面向企业和个人的无代码/低代码平台，通过串联 Elements 来创建自定义 AI 聊天机器人。用户可交互式地选择并连接预置的 Elements（涵盖聊天界面、LLM 集成与数据管理），快速部署量身定制的聊天解决方案。交互式 AI 工作坊软件：一款教学工具，让教师和学生通过使用 Elements 构建图形化或基于 API 的 AI 应用来探索 AI 概念。它能帮助学习者把 AI 工作流可视化，在课堂环境中通过连接 Elements 理解 AI 系统的各个组成部分。AI 模型实验套件：面向数据科学家和 AI 研究人员的平台，通过把 Elements 组装成工作流来对机器学习模型进行原型设计与测试。他们可以轻松替换或修改用于模型创建、数据处理和结果可视化的 Elements，从而快速迭代 AI 解决方案。基于 LLM 的 API 创建器：一项让开发者通过组合多种面向 API 设计的 Elements 来创建自定义 API 的服务。通过选择合适的 Elements 并将其连接，把搭载不同模型和端点的 LLM 集成到 API 中，提供所需功能。交互式文档生成器：为软件项目自动生成交互式文档的工具。用户可以通过连接 Elements 来设计演示 API 功能的界面，让最终用户能够体验实时、可交互的 API 文档。协作式 AI 开发环境：允许多名用户通过可视化地串联 Elements 与 Payloads 同时协作开发 AI 项目的平台。该服务支持版本控制、实时协作以及团队成员之间共享 AI 工作流。AI 驱动的数据分析仪表盘：通过连接用于数据处理、LLM 交互和可视化的 Elements，把数据分析与 LLM 相结合的应用。用户可以借助可定制的 Elements 创建提供洞察与预测的个性化仪表盘。可定制的虚拟助手界面：用于创建虚拟个人助手的交互工具，通过串联相关 Elements 并借助 LLM 的函数与交互式聊天界面来处理日程安排、提醒和信息检索等任务。游戏 AI 开发套件：帮助游戏开发者通过组装能模拟决策、并用 LLM 生成对白的 Elements，创建智能 NPC 或游戏角色，打造动态且富有交互性的游戏内体验。AI 驱动的客户支持门户：可定制的平台，通过选择用于处理常见问题（FAQ）、聊天交互和反馈收集的 Elements 来构建自动化客户支持系统，全部由可灵活适配的 LLM 语言处理模型支撑。

## 优势
可扩展的模块化：优先考虑可扩展性与模块化，让开发者能用干净、直观的接口轻松定制并创建新的 Elements。观察者模式端口：端口连接采用观察者模式，通过事件通知把输出端口与输入端口相连，实现 Elements 之间的通信。基于组件的架构：采用由 Models 和 Views 构成的组件化设计来处理数据逻辑与 UI，增强 Element 与 Payload 构建的灵活性。

## 简介
Pyllments 面向希望借助图形化和基于 API 的界面、构建具备 LLM 能力的模块化可扩展 Python 应用的开发者，有助于促进组件复用与 UI 一致性。

## .cursorrules 提示词概述
.cursorrules 文件描述了一个名为 "Pyllments" 的 Python 库，它通过连接称为 Elements 的模块化组件，来构建涉及 LLM（大语言模型）的图形化和基于 API 的应用。每个 Element 由负责数据与逻辑的 Model 和负责 UI 交互的 Views 组合而成。这些 Elements 通过 Ports 互联，实现基于观察者模式的动态通信。Payload 是另一种组件类型，同样拥有自己的 Model 和 Views，在 Elements 内部承担数据处理与 UI 生成。该项目正在发展为一个完整的框架，重点提供可扩展性、模块化和可定制接口等对开发者友好的特性。该库使用 Panel 进行可视化、使用 Param 实现类参数化、使用 Langchain 处理 LLM 工作流。Docstrings 应遵循 NumPy/SciPy 文档风格。
