作者：Raphael MANSUY

## 你可以构建什么
命令行自动化套件：使用 Python 以及由 click 和 prompt-toolkit 驱动的丰富 CLI 界面，开发自动化文件管理、文本处理、数据转换等重复性任务的命令行工具。交互式数据校验工具：使用 pydantic 做类型检查、校验和处理数据文件（如 CSV、JSON）的命令行应用，用 rich 提供富文本反馈、tqdm 显示进度。基于模板的报告生成器：使用 jinja2 从模板生成可定制报告的工具，允许用户通过交互式命令行界面指定参数。带文本格式化的剪贴板管理器：使用 pyperclip 和 colorama 支持富文本格式和 unicode 操作的剪贴板管理器，适合频繁复制粘贴代码片段的开发者和写作者。交互式文件系统浏览器：以直观界面探索和操作文件系统的命令行工具，支持个性化快捷方式，并用 tabulate 增强目录列表的可视化。实时命令行聊天界面：面向命令行的实时消息应用，使用 prompt-toolkit 进行交互、colorama 着色消息，适合服务器环境中的开发者协作。代码片段分词工具：使用 tiktoken 对代码片段或文本输入进行分词与分析的工具，通过友好的命令行界面提供洞察与统计。渐进式学习 CLI 测验：就 Python 和软件开发主题对用户进行测验的命令行应用，使用 click 处理交互、tqdm 显示进度。基于 Poetry 的依赖管理 UI：通过终端界面管理 Python 项目依赖的增强版 poetry 依赖管理器，简化包版本更新与安装任务。Pyperclip 增强复制粘贴工具：扩展剪贴板功能的工具，直接从命令行提供自动格式化和宏操作选项。

## .cursorrules 提示词概述
.cursorrules 文件描述了一位精通 Python、命令行工具和文件系统操作的精英软件开发者的职责与素质。它强调务实的编码方法、模块化设计、KISS 和 DRY 等有原则的编码实践，以及文档与测试的重要性。该开发者应偏好函数式编程，使用的技术栈包括 Python 3.6+，以及 `rich`、`click`、`jinja2`、`prompt-toolkit` 等多种依赖，用于构建健壮的命令行应用，并通过测试与校验保证代码质量。
