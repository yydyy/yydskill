# Plasticode Telegram API（.cursorrules prompt 文件）

作者：Sergey Atroshchenko

## 可以构建的内容（What You Can Build）
Plasticode CMS 增强工具：一个为 Plasticode CMS 提供额外插件和模块的 Web 应用，利用面向对象的 PHP 原则和依赖注入，让开发者无需重复代码即可轻松增强和定制自己的 CMS。Telegram Bot 管理平台：一项允许用户使用 Telegram Bot API 创建和管理 Telegram 机器人的 Web 服务。该服务遵循 SOLID 原则，确保平台模块化且易于扩展新功能。PHP 数据校验库：一个 Composer 包，帮助开发者校验 PHP 应用中的数据，与现有 Plasticode 项目无缝集成，并利用 PHP 7.4 特性提供现代、健壮的校验方案。错误处理与日志工具包：一个面向 Plasticode 应用的 PHP 库，实现恰当的错误处理和日志记录，使用符合 PSR-12 的代码和 PHP 的 try-catch 块有效管理异常，提供清晰、有条理的错误报告。PHP 依赖注入容器：一项提供健壮、轻量 DI 容器的服务，专为 PHP 应用设计，遵循 PSR-12 标准，易于集成到 Plasticode 项目，以改善应用架构并高效管理依赖。迭代式编码学习平台：一个通过迭代和模块化最佳实践教授 PHP 和 Plasticode 的教育平台，提供代码示例和练习，聚焦实现 SOLID 原则和依赖注入等概念。模块化 PHP 单元测试框架：一个由 Composer 管理、为 PHP 应用量身定制的框架，支持模块化和以迭代为核心的开发，设计为与 Plasticode 集成，遵循最佳编码标准提供全面的单元测试能力。描述性代码片段仓库：一个基于 Web 的 PHP 代码片段仓库，变量和方法命名具有描述性，遵循 PSR-12 标准，旨在为开发者提供可轻松用于 Plasticode 及其他 PHP 项目的最佳实践示例。自动化代码重构服务：一项 PHP 服务，分析并重构代码库，确保遵循面向对象原则、SOLID 设计和首选编码实践（如减少重复、增强模块化），专门面向 Plasticode 项目。

## 简介（Synopsis）
开发者可以使用 PHP 和 Plasticode 构建健壮的 Telegram 机器人，遵循 SOLID 原则和 PSR-12 标准，同时利用 Composer 进行高效的依赖管理。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件面向使用 PHP、Plasticode 和 Telegram Bot API 的开发者，引导他们遵循 Web 开发最佳实践。它强调撰写简洁、技术性的回答，使用面向对象编程并遵循 SOLID 原则。该文件鼓励开发者优先考虑迭代和模块化以避免代码重复，为变量和方法使用描述性命名，并优先采用依赖注入。它规定使用 PHP 7.4 特性，遵守 PSR-12 编码标准，并包括用 try-catch 块实现恰当的错误处理。提到的依赖包括用于管理依赖的 Plasticode 和 Composer。
