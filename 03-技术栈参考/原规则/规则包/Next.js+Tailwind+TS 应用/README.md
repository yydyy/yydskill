## 可以构建什么（What You Can Build）
Next.js Tailwind 博客起步模板：一个 Web 应用模板，提供用 Next.js 创建博客的样板工程，使用 Tailwind CSS 做样式、TypeScript 保证类型安全。该模板可与 Supabase 集成，实现认证和数据存储等后端功能。它包含亮色与暗色模式，并配有适合现代用户界面的配色方案。电商管理后台：一个在线平台模板，允许用户使用 Next.js、Tailwind CSS 和 TypeScript 创建电商管理后台。以 Supabase 为后端，它可提供商品管理、用户认证和订单跟踪等功能，并具备带亮/暗模式选项的响应式设计。Langchain 集成工具包：一个指导开发者将 Langchain 最新特性集成到 Next.js 应用中的工具包。它提供 TypeScript 示例项目和代码片段，以及使用 Langchain 创建 RAG（检索增强生成）应用的 Tailwind CSS 文档。Supabase 认证系统：一个即插即用的认证系统，适用于任何使用 Supabase 的 Next.js 应用。该方案提供用 TypeScript 编写、Tailwind CSS 样式化的预制组件，具备注册、登录和密码找回功能，并适配响应式设计。作品集网站搭建器：一个基于 Next.js 的平台，用户可在其中构建和定制自己的作品集网站，用 Tailwind CSS 做样式、TypeScript 处理逻辑。它可借助 Supabase 存储项目详情和简历数据，并提供亮色与暗色两套主题以匹配不同的审美偏好。实时聊天应用：一个示例项目，演示如何使用 Next.js、Tailwind CSS、TypeScript 和 Supabase 实时数据库构建实时聊天应用。该项目将展示环境搭建、用户认证和消息存储，重点在于清晰、模块化的代码。多主题模板：一个 Next.js 应用代码模板，突出展示超越亮/暗模式、切换多种主题的能力，使用 Tailwind CSS 和 TypeScript 实现。它将展示实现用户主题偏好并将其持久化到 Supabase 等数据库中的实际用例。类型安全表单生成器：一个用于生成表单组件的实用工具，使用 Next.js 构建、Tailwind 样式化，并用 TypeScript 确保类型安全。该工具使用 Supabase 管理表单数据，并提供可复用的组件和 hooks 用于校验和提交表单。互动学习平台：一个利用 Next.js 生态构建教育平台的框架。它以 TypeScript 保证类型正确性，用 Tailwind CSS 构建 UI 组件，并用 Supabase 管理课程、测验和学生进度。平台拥有清晰可读的代码库，同时支持亮色与暗色主题。现代博客平台：一个采用前沿 Next.js 的博客平台，提供基于 Tailwind CSS 的可定制主题，并用 TypeScript 强制类型。该应用集成 Supabase 提供文章管理、订阅和用户交互等后端服务，展示构建可扩展应用的最佳实践。

## .cursorrules 提示文件概述（Overview of .cursorrules prompt）
.cursorrules 文件定义了专家级编程助手的行为与准则，专注于使用 Tailwind 和 TypeScript 创建 Next.js 应用。它强调使用最新版本和最新特性的 Next.js、TypeScript、Tailwind CSS 和 Supabase。助手应提供深思熟虑且符合事实的解决方案，用伪代码制定分步计划，并开发安全、功能完备、可读的代码。它强调准确性、完整性以及对用户需求的遵循，同时把可读性置于性能之前，并确保实现中不遗漏任何要素。
