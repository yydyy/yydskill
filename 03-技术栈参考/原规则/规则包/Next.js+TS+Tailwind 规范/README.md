## 你可以构建什么
去中心化应用模板生成器：开发一个提供模板的工具，用于创建基于 Autonomys 网络的去中心化应用（dApp），让开发者能轻松地在标准化基础上进行构建。AI 文档生成器：创建一个 AI 工具，为构建在 Autonomys 网络上的应用生成文档，利用代码结构提供全面的指南和 API 参考。响应式 UI 组件库：开发一个可复用、响应式 UI 组件库，专为 Autonomys 网络设计，确保无障碍性并遵循 Tailwind CSS 指南。AI 代码审查服务：实现一项用 AI 审查 TypeScript 和 Next.js 项目代码的服务，聚焦最佳实践，就代码可维护性和性能给出改进建议。实时错误处理仪表盘：为开发者打造一个仪表盘，实时显示 Autonomys 网络上应用的错误处理和用户输入校验日志，提升调试效率。分布式存储文件管理器：创建一个帮助用户管理其在 Autonomys 网络分布式存储系统中文件的应用，具备上传、下载和确保数据完整性的功能。计算资源分配查看器：构建一个可视化 Autonomys 生态内分布式计算资源分配与使用情况的工具，助力高效的资源管理。H+AI 协作平台：设计一个促进人与 AI 交互的协作平台，提供用于在 deAI 生态上开发和部署 AI 应用的工具和界面。学院学习追踪器：在 Autonomys Academy 网站上实现一个功能，追踪用户学习材料的进度，提供个性化推荐和成就。Autonomys 网络状态监控器：创建一个 Autonomys 网络监控应用，提供网络健康、活动和区块链数据的洞察，对开发者和用户都有用。

## 简介
区块链开发者和 Web 开发者可以使用本提示词，利用 Next.js 和 TypeScript 为 Autonomys 网络构建去中心化的区块浏览器应用。

## .cursorrules 提示词概览
`.cursorrules` 文件概述了一个名为 Astral 的项目的结构和开发指南，该项目是 Autonomys 网络的区块浏览器（Block Explorer）。它使用 Next.js 和 TypeScript 构建，集成了状态管理、UI 组件和数据获取相关的库。文件列出了项目相关的关键 URL，提供了项目结构概览，并指定了强调 TypeScript、响应式、无障碍性以及使用 Tailwind CSS 进行样式设计的开发指南。它详述了开发和生产构建的重要脚本、遵循 React 最佳实践的 AI 交互指南，并收录了 Autonomys 生态的相关术语。另附有可供进一步参考的资源链接。
