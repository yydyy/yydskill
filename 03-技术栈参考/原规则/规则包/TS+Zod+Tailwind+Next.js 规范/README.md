## .cursorrules 提示文件概述
`.cursorrules` 文件概述了一套全面的 TypeScript 应用编码风格指南，聚焦代码结构、命名约定和 TypeScript 用法。它强调函数式编程、迭代和模块化，推荐使用 interface、map 和 Zod 进行表单校验。指南建议使用特定的 UI 库和 Tailwind CSS 响应式设计，推广动态加载、懒加载等性能优化技术。它还强调错误处理、日志记录和用户友好的提示信息，建议使用服务端组件、提前返回和守卫子句。此外，文件给出了管理 URL 状态、优化 Web Vitals，以及与 React Remix 和 Next.js 集成进行数据获取和路由的指南。
