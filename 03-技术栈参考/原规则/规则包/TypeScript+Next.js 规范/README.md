## .cursorrules 提示词概览
该 .cursorrules 文件为使用 Node.js、Next.js App Router、Drizzle ORM、React、Daisy UI 和 Tailwind 开发 TypeScript 应用提供指导准则。它推荐使用 'bun' 作为包管理器，并强调在编写安全、实用、高效的代码之前进行分步规划和详细伪代码的重要性。文件提倡使用函数式和声明式编程模式、描述性变量命名、简洁语法和模块化，以提升代码可读性。它规定了 TypeScript、Daisy UI 和 Tailwind CSS 的样式用法，并鼓励通过服务端组件、动态加载和图片优化来进行性能优化。此外，它还建议遵循 Next.js 文档中关于数据获取、渲染和路由的最佳实践。
