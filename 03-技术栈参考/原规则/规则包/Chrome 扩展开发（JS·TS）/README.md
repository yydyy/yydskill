# Chrome 扩展开发（JS·TS）.cursorrules 提示文件

作者：penkzhou

## 你可以构建什么
交互式学习 Chrome 扩展：开发一款在浏览器中直接提供交互式编程课程与测验的 Chrome 扩展。它可以利用 TypeScript 为练习做类型检查，并使用 Radix UI 打造视觉精美、易于使用的界面。注重隐私的广告拦截器：创建一款使用最新 manifest 版本（v3）并遵守严格内容安全策略、高效拦截广告的 Chrome 扩展。该工具可用 JavaScript 动态隐藏广告，并用 Tailwind 为任何 UI 组件设置样式。网站性能分析器：开发一款分析并报告网站性能的 Chrome 扩展。它可以调用 Chrome 的性能 API，用 Shadcn UI 在仪表板中展示数据，并基于 CSS 与 JS 最佳实践给出优化建议。带标签系统的书签管理器：构建一款配有强大标签系统、便于用户管理书签的 Chrome 扩展。使用 chrome.storage 做状态管理，并用 Flexbox 布局、CSS Grid 组织内容，提供简洁、响应式的 UI。安全密码管理器：创建一款基于 TypeScript 的 Chrome 扩展，用于管理和生成安全密码。使用 chrome.storage API 实现安全存储机制，并让用户通过样式精美的弹窗界面访问自己的密码。跨浏览器标签同步器：开发一款利用 WebExtensions API 在不同浏览器间同步已打开标签页的 Chrome 扩展。使用事件驱动架构检测标签页变化，并用 chrome.storage 维护持久状态。可定制新闻聚合器：构建一款聚合用户所选来源新闻的 Chrome 扩展。实现一个可配置的选项页，让用户输入偏好，并借助 Tailwind 打造统一、响应式的 UI。专注模式生产力工具：创建一款 Chrome 扩展，通过拦截让人分心的网站并使用 chrome.alarms 按设定间隔发送提醒来帮助用户保持专注。实现可选权限，让用户自定义被拦截网站清单。语言翻译助手：开发一款提供页面内翻译与语言学习辅助的 Chrome 扩展。使用 Web API 进行翻译，并用 shadcn UI 以直观的工具提示或侧边栏形式呈现译文。用户活动追踪器：构建一款追踪并记录用户跨网站活动的 Chrome 扩展，帮助用户分析自己如何花时间上网。确保数据存储安全，并通过对追踪数据匿名化来落实以隐私为核心的功能。自动表单填充器：创建一款基于 TypeScript 的 Chrome 扩展，检测网页表单并提议用已保存的信息填充。使用安全的存储系统，并提供弹窗让用户管理已保存的数据。带情境通知的待办清单：开发一款把待办清单集成进浏览器的 Chrome 扩展，依据已打开的标签页或时间段等情境发送通知，利用 chrome.alarms 与 chrome.notifications。图片下载整理器：创建一款 Chrome 扩展，让用户从网络下载图片并自动归类到指定文件夹。用 Radix UI 设计简洁的拖放界面，用于分类下载队列。面向 Web 开发者的 SEO 分析工具：构建一款为任意网页提供实时 SEO 洞察的 Chrome 扩展。借助浏览器 API 读取页面元数据，并用 Tailwind 保持样式一致，把结果渲染成综合报告。语法与拼写检查器：开发一款在全网文本输入框中高亮语法与拼写错误的 Chrome 扩展。实现后台脚本，使用可靠的语言处理 API 进行分析并给出修正建议。

## 简介
开发 Chrome 扩展的开发者将受益于本提示：借助现代 JavaScript 实践与 TypeScript，构建结构良好、安全且高效的扩展，确保跨浏览器兼容性与最佳性能。

## .cursorrules 提示文件概述
.cursorrules 文件为使用 JavaScript、TypeScript、HTML 与 CSS 构建 Chrome 扩展的开发者提供指南。它涵盖代码风格与结构，倡导简洁的函数式编程与描述性命名约定，并鼓励使用 TypeScript 保障类型安全。文件概述了扩展架构的最佳实践，包括关注点分离、状态管理与消息传递；强调安全，给出权限、内容安全策略与数据校验方面的指南；还包括 UI 与样式建议、性能优化技巧与浏览器 API 使用策略。跨浏览器兼容性、测试与调试实践以及情境感知的开发考量也有所涉及。文件强调务必遵循 Chrome 扩展文档中的最佳实践。
