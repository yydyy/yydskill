## 你可以构建什么
Go API 代码生成器：一个工具，使用 net/http 包为 RESTful API 生成 Go 代码，遵循最新的 Go 标准（包括 Go 1.22 的 ServeMux），支持通配符匹配和正则路由等特性。Go RESTful API 模板服务：一个 Web 服务，提供 Go RESTful API 模板，通过预定义的结构、错误处理、日志和中间件配置帮助开发者快速启动项目。在线 Go API 验证器：一个网站，开发者可以粘贴自己的 Go API 代码，使用最新的 Go 特性针对 API 设计、错误处理、安全性和性能的最佳实践进行校验。API 的 Go 并发分析器：一个应用，分析 Go API 并提出改进建议，以最优方式使用并发特性，提升 RESTful 服务的性能和可扩展性。基于标准库的 Go API 中间件库：一个库，提供针对常见 API 任务的预置中间件函数，如日志、身份验证、限流和输入校验，专门为 Go 的 net/http 包量身定制。Go API 安全检查器：一个安全评估工具，扫描 Go API 代码中的漏洞，确保实现了正确的身份验证、授权和输入校验。Go API 测试框架：一个专门为 Go API 设计的测试框架，允许开发者利用 Go 的 testing 包测试端点，配置简单便捷。交互式 Go ServeMux 路由构建器：一个交互式平台，帮助开发者可视化地设计和测试 API 路由，支持通配符和基于正则的路由等特性。Go API 性能分析器：一个用于对 Go API 进行性能分析和基准测试的在线工具，利用标准库的并发特性，提供性能瓶颈洞察和优化建议。全面的 Go API 文档生成器：一个服务，为 Go API 生成专业详尽的文档，包括示例、端点说明和符合 RESTful 标准的最佳实践。

## 简介
开发者使用 Go 构建可扩展、安全的 RESTful API，利用 net/http 包和 ServeMux 实现高效的路由和并发。

## .cursorrules 提示内容概述
.cursorrules 文件概述了面向使用 Go 编程语言创建 API 的 AI 编程助手的指南，具体使用 `net/http` 包和 1.22 版本引入的 ServeMux 特性。它强调遵循 RESTful API 设计原则、Go 惯用写法和最佳实践，确保开发出正确、无 bug 且高效的 API。文件指导开发者先用伪代码规划 API 结构，彻底确认计划，然后再开始编码。它涵盖 API 开发的各个方面，包括 HTTP 方法处理、错误处理、响应格式化、输入校验、并发、日志、中间件、限流和安全。文件还建议采用 Go 的 testing 包制定测试策略，并在 API 设计中注重安全性、可扩展性和可维护性。
