## 你可以构建什么
Kubernetes 文档生成器：一款自动化创建全面 Kubernetes 文档的高级工具，采用最新的稳定版本、最佳实践和 MkDocs。用户可以输入 Kubernetes 配置，工具会生成结构化的用户指南、教程和 API 参考文档。
云原生文档服务：一项为云原生项目提供定制化文档解决方案的在线服务。该服务提供专业技术写作、架构图绘制，以及 MkDocs 的落地实施，打造流畅且用户友好的文档。
基于 Markdown 的文档平台：一个帮助技术写作者使用 Markdown 和 MkDocs 创建、组织和维护云原生文档的网站或应用。该平台包含协作编辑、基于 Git 的版本控制和内置风格指南强制执行等功能。
Kubernetes 最佳实践仓库：一个精选仓库，提供关于 Kubernetes 最佳实践、容器化和微服务架构的 Markdown 文档。该仓库包含常见任务操作说明、故障排查指南和发布说明，作为专业人士的参考资料。
交互式 Kubernetes 教程中心：一个教育平台，提供在 Kubernetes 上部署和管理应用的交互式分步学习模块。这些模块包含代码片段、命令行示例和实战场景，确保动手学习。
技术写作风格指南应用：一款帮助技术写作者在多个文档项目中建立并保持一致风格的应用。它提供为云原生和 Kubernetes 文档量身定制的指南，确保术语和格式一致。
SEO 优化文档仪表盘：一项借助元数据、标签和 SEO 友好的页面标题对文档进行搜索引擎优化的服务。该工具与 MkDocs 集成，提升技术内容在网上的可发现性。
云原生协作平台：一款促进技术写作者、开发者和云原生专家实时协作的应用。功能包括文档评审、更新，以及与 Git 等版本控制系统的集成。
MkDocs 元数据增强工具：一款优化 MkDocs 元数据处理的插件，改进技术文档中的导航和搜索功能，旨在提升用户浏览文档站点的体验。
AI 驱动的文档助手：一款帮助技术写作者起草、评审和更新云原生文档的数字助手。它借助 AI 提出修正建议、填补内容空白，并为复杂概念提供额外的上下文和解释。

## 简介
开发者和技术写作者可以使用这一提示词，通过 Markdown 和 MkDocs 为云原生技术、Kubernetes 项目和文档站点创建全面而高效的文档。

## .cursorrules 提示文件概述
`.cursorrules` 文件阐述了创建云原生技术相关技术文档的指南与最佳实践，重点聚焦 Kubernetes、Markdown 和 MkDocs。它强调产出清晰、简洁、技术准确的内容，具备合理的结构、统一的格式和全面的主题覆盖。该文件为记录云原生概念、Kubernetes 组件和 MkDocs 用法提供了详细说明，突出技术准确性、易用性、协作和版本控制在文档工作中的重要性。此外，文件规定了使用元数据以增强 SEO，并要求遵守特定的文档标准，确保内容完整、用户友好且保持最新。
