# TypeScript Node.js Next.js 应用 .cursorrules 提示文件

作者：Christoph Black

## 可以构建什么
具备高级功能的笔记 Web 应用：使用 TypeScript、Node.js 和 Next.js，配合 Shadcn UI 和 Tailwind 样式，开发一个功能全面的笔记应用。功能包括新增笔记、查看全部笔记列表、详情视图、编辑和删除笔记。应用将集成搜索框、筛选器、排序选项、分页、加载状态、错误处理和拖放功能。拖放式笔记整理工具：创建一个聚焦拖放功能的 Web 应用，让用户能以可视化方式轻松整理笔记并排列优先级。使用 Radix UI 实现无障碍性、Tailwind 做样式、Next.js 做服务端渲染。移动优先设计的响应式笔记应用：构建一个首先面向移动用户的响应式笔记应用。利用 Tailwind CSS 实现响应式设计，确保在所有设备上都有最佳体验。包含搜索、筛选和排序等功能。使用 React Server Components 优化的笔记应用：使用 React Server Components 设计一个经过性能优化的笔记应用。通过服务端渲染，并仅在必要时动态加载组件，最大限度减少客户端状态管理。SEO 友好的笔记管理平台：实现一个注重 SEO 和 Web Vitals 优化（LCP、CLS、FID）的笔记管理平台。利用 Next.js 的服务端数据获取和路由能力，提升搜索引擎可见性和页面加载速度。支持实时更新的协作笔记应用：创建一个允许多名用户同时编辑笔记的协作式笔记应用。使用 Web Sockets 进行实时更新，用 Shadcn UI 提供直观的用户交互。无障碍优化的笔记应用：使用 Radix UI 组件开发一个注重无障碍性的笔记应用。实现键盘导航、屏幕阅读器支持、高对比度主题等无障碍功能。离线优先的笔记应用：使用 localStorage 或 IndexedDB 进行数据持久化，设计一个离线优先的笔记应用。允许用户即使在没有网络连接时也能访问和修改笔记。支持自定义选项的主题化笔记应用：构建一个提供主题自定义的笔记应用，用户可使用 CSS 变量和 Tailwind 类选择不同的配色方案或布局偏好。集成云存储同步的笔记应用：创建一个与主流云存储服务（如 Google Drive、Dropbox）集成的笔记应用，跨设备同步笔记，确保随时随地都能访问。

## 简介
熟悉 TypeScript、Node.js 和 Next.js App Router 的开发者可以使用本提示，构建一个具备完整 CRUD 功能和现代 UI 的健壮、优化的笔记应用。

## .cursorrules 提示概览
该 .cursorrules 文件概述了使用 TypeScript、Node.js、Next.js、React、Shadcn UI、Radix UI 和 Tailwind CSS 开发 Web 应用的编码指南与最佳实践。它强调编写简洁且技术性强的 TypeScript 代码，使用函数式与声明式模式，优先采用模块化和描述性命名约定。文件规定使用 TypeScript interface 而非 type，并给出了各种语法与格式偏好。在 UI 与样式方面，它要求使用 Shadcn UI、Radix 和 Tailwind CSS，并采用移动优先的方法。性能优化指导包括最小化客户端函数、利用 React Server Components、优化图片以及使用动态加载。关键约定涵盖状态管理、优化 Web Vitals，以及遵循 Next.js 文档进行数据获取和路由。最后，它概述了笔记应用的需求，包括新增、列出、编辑和删除笔记等功能，以及搜索、筛选、排序、分页、加载、错误状态和拖放功能。
