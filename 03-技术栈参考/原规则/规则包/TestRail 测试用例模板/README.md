# TestRail 测试用例提示词

一份专用的 .cursorrules 提示词，用于创建标准化的 TestRail 测试用例，包含清晰的步骤、预期结果和测试数据，便于高效的测试管理与执行。

## 你可以构建什么

- **结构化测试用例**：面向 TestRail 的标准化、全面的测试用例
- **测试流程**：附带预期结果的清晰分步说明
- **测试套件**：相关测试用例的有序集合
- **负面测试场景**：验证对无效输入进行正确处理的测试用例
- **跨平台测试计划**：可适配不同环境的测试用例

## 优势

- **标准化格式**：所有测试用例保持一致的结构
- **完整的文档**：全面覆盖测试场景
- **清晰的预期结果**：每个测试步骤都有明确的成功标准
- **高效执行**：易于遵循和执行的测试用例
- **提升测试覆盖**：鼓励充分测试的模板
- **TestRail 兼容性**：与 TestRail 结构对齐的格式

## 简介

本提示词帮助 QA 工程师为 TestRail 创建标准化、全面的测试用例，为测试人员提供清晰的测试执行和验证说明，同时确保充分的测试覆盖。

## .cursorrules 提示词概览

`.cursorrules` 提示词通过以下关键要素指导用户创建有效的 TestRail 测试用例：

- **标准化结构**：包含所有 TestRail 必要部分的完整模板
- **详细示例**：正面和负面测试用例的全面示例
- **最佳实践**：编写有效测试用例的十项关键原则
- **TestRail 特有事项**：关于 TestRail 特定字段和注意事项的指导
- **适配性指导**：针对不同项目定制测试用例的建议
- **表格格式**：以表格形式清晰呈现步骤和预期结果
