# Next.js SEO 开发 .cursorrules 提示文件

作者：Rostyslav

## 可以构建什么
Next.js 项目脚手架生成器 - 一个让开发者快速生成 Next.js 项目的工具，包含如 package.json 文件中所见的预定义配置、依赖和脚本，帮助他们高效启动开发流程。依赖管理仪表板 - 一个 Web 应用，提供项目依赖的洞察，包括版本更新、潜在漏洞，以及基于 package.json 的依赖树可视化。自动化脚本测试器 - 一个动态测试 package.json 中定义的 NPM 脚本以验证其功能的应用，为用户提供问题报告或潜在优化建议。代码注释校验器 - 一项分析项目中代码注释的服务，确保注释全面且与时俱进，尤其关注代码已变更、可能需要新注释的地方。Next.js 模块更新器 - 一项自动检查 Next.js 模块和依赖最新版本并提供模块更新建议的服务，确保项目始终拥有最新功能和安全补丁。Prettier 与 ESLint 配置应用 - 一个 Web 工具，让用户通过直观的 UI 轻松为其 Next.js 项目配置 Prettier 和 ESLint，更新 package.json 及其他相关文件。自定义脚本构建器 - 一个帮助创建契合项目需求的自定义 NPM 脚本的 Web 应用，让用户扩展 package.json 中定义的功能。TSLint 转 ESLint 转换器 - 一项帮助把 TSLint 配置转换为 ESLint 配置的服务，面向需要符合 Next.js 和现代 JS 标准的 TypeScript 项目。React 组件库集成器 - 一个帮助把 DaisyUI 或 Heroicons 等流行 React 组件库集成到 Next.js 项目的工具，自动配置依赖并搭建示例组件。版本冲突解决器 - 一个识别并解决 package.json 中列出的依赖之间版本冲突的应用，确保安装和构建顺利进行。

## 简介
维护 Next.js 应用的开发者可以受益于确保一致的代码文档和版本管理，同时遵守特定准则并保留关键注释。

## .cursorrules 提示概览
1. 该 .cursorrules 文件提供了维护与 Next.js 应用关联的 package.json 文件的说明。它强调为代码添加有帮助的注释，并建议不要改动带有特定注释的行。package.json 文件指明了应用的名称、版本、构建与运行应用的脚本及其 dependencies 和 devDependencies，其中包括 Next.js、React、TypeScript、ESLint 和 TailwindCSS 等各种库和工具。此外，还有处理 vercel 部署的配置以及用于开发和生产构建的脚本命令。
