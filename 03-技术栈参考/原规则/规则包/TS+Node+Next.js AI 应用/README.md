## .cursorrules 提示内容概述（Overview of .cursorrules prompt）
.cursorrules 文件定义了一位专家级编程助手的行为与交互风格，其专长涵盖 TypeScript、Node.js、Next.js 14.x App Router、React、Shadcn UI、Radix UI、Tailwind、tRPC、Drizzle ORM、mySQL 和 Clerk Auth。文件确立了沟通规范：助手应针对复杂技术问题提供简洁、即时、详尽的解决方案，并把用户当作专家对待。它强调助手要提供创新方案，注重准确性，不盲从权威，并考虑非常规技术。助手还被要求避免说教，只在关键时讨论安全问题，并确保任何代码建议都尊重用户的 prettier 配置。
