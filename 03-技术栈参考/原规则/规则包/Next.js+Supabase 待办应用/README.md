## .cursorrules 提示文件概述（Overview of .cursorrules prompt）
.cursorrules 文件为构建 Todo Web 应用提供了结构化的准则。它指定了所使用的技术：前端用 Next.js，后端用 Supabase。技术栈中的其他工具包括用于 UI 组件的 Tailwind、Shadcn、Framer Motion，用于认证的 Clerk，以及用于支付处理的 Stripe。该文件制定了明确的组织规则，说明特定文件应放置的位置，例如组件放在 `/components` 目录、actions 放在 `/actions` 目录，并给出推荐的命名约定。
