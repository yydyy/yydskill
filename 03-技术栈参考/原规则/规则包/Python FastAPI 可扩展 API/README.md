## .cursorrules 提示文件概述
.cursorrules 文件为使用 Python、FastAPI、TypeScript、React、Tailwind 与 Shadcn UI 开发可扩展 API 与应用提供指南与最佳实践。它确立了代码编写的关键原则，如给出简洁、专业且带清晰示例的回复，偏好函数式编程模式而非类。文件概述了前端与后端的项目结构，详述技术栈、目录结构与重要配置文件，并规定了代码风格与结构、性能优化技术、项目约定以及测试与部署实践。这些框架旨在确保 API 与 Web 应用的高效、可维护与高性能开发。
