## 你可以构建什么
Drawscape Factorio 可视化应用：创建一个 Web 应用，允许用户上传来自 FUE5 MOD 的 JSON 文件，并使用自定义主题、配色方案和图层生成其 Factorio 布局的 SVG 可视化。Factorio 布局协作平台：开发一个平台，让 Factorio 玩家可以分享和协作工厂布局。用户可以导入 FUE5 MOD 数据、生成 SVG 视觉效果，并实时标注或修改布局。Factorio 交互式 SVG 编辑器：设计一个不仅能可视化、还允许用户交互式编辑 Factorio SVG 布局的工具，通过友好的界面修改资产、传送带、墙壁等元素。Factorio 布局自动报告生成器：构建一个自动化系统，接收来自 FUE5 MOD 的 JSON 输入，使用 Drawscape Factorio 进行可视化，并创建包含视觉和文本数据分析的工厂布局详细报告。Factorio 主题定制门户：提供一项服务，允许用户为其 Factorio 可视化定制主题和配色方案，并使用 Drawscape Factorio 模块将其应用到布局。Factorio 可视化 API 服务：开发一个提供端点的 API，让用户提交 FUE5 MOD JSON 数据并接收定制的 Factorio 布局 SVG 可视化，可轻松集成到现有系统。Factorio 玩家教育资源：创建教程和文档等教育材料，介绍使用 Drawscape Factorio 模块可视化和优化 Factorio 布局，帮助玩家有效使用该工具。Factorio 社区展示：上线一个网站，让 Factorio 玩家公开展示他们最好的工厂布局，使用 Drawscape Factorio 模块进行可视化和增强，促进社区互动与灵感。IDE 的 Drawscape Factorio 插件：为流行 IDE 开发集成 Drawscape Factorio 模块的插件，让开发者在编码时轻松可视化 FUE5 MOD JSON 数据。Factorio 可视化主题市场：创建一个市场，设计师可以在其中出售供 Drawscape Factorio 模块使用的自定义主题和配色方案，让用户进一步个性化其可视化效果。

## 概要
从事 Factorio 自动化和可视化的开发者可以使用此提示词创建一个 Flask API，将 FUE5 MOD 的 JSON 数据通过 Drawscape Factorio 转换为 SVG。

## .cursorrules 提示词概览
该 .cursorrules 文件提供了使用自定义 Drawscape Factorio Python 模块的说明。其中包括如何导入模块、加载来自 FUE5 MOD 的 JSON 文件、解析 JSON 数据，然后使用解析后的数据生成带特定设置（如主题名称、配色方案和可见图层）的 Factorio 主题 SVG 文件的示例。此外，它还提供了 `environment.yml` 文件，列出了运行项目所需的依赖和 Python 版本，包括 Flask、svgwrite 和 numpy 等库。
