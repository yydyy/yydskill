# Cypress 集成测试提示

一个专门的 .cursorrules 提示，用于使用 Cypress 创建全面的集成测试并支持 TypeScript。

## 可以构建什么

- **集成测试套件**：验证 UI 与 API 组件之间交互的测试
- **关键用户流程测试**：覆盖跨多个组件的核心用户旅程的测试
- **基于 API Mock 的测试**：带有受控 API 响应场景的集成测试
- **状态转换测试**：对组件交互过程中应用状态变化的校验
- **跨组件测试**：验证相连组件之间数据流的测试

## 优势

- **完整的组件交互覆盖**：验证组件如何协同工作的测试
- **API 依赖隔离**：使用 cy.intercept 控制 API 响应，实现可靠测试
- **真实用户旅程测试**：聚焦用户实际经历的关键流程
- **恰当的状态校验**：验证 UI 状态根据 API 响应正确更新
- **错误路径覆盖**：同时测试正常路径和错误场景
- **可维护的测试组织**：描述性的测试结构，让组件集成一目了然

## 简介

本提示帮助 QA 工程师用 Cypress 创建高质量的集成测试，聚焦 UI 组件与 API 以及彼此之间的交互，确保关键用户流程在整个应用中正确运行。

## .cursorrules 提示概览

该 .cursorrules 提示指导 QA 工程师使用 Cypress 创建有效的集成测试，包含以下关键要素：

- **TypeScript 检测**：自动检测并适配项目中的 TypeScript 使用情况
- **集成测试重点**：关于测试组件交互和关键用户流程的指南
- **最佳实践**：集成测试的八项基本实践，包括关键流程、data-testid 的使用和 API mock
- **示例测试模式**：表单提交和购物车两种场景的详细集成测试示例
- **API Mock 策略**：在集成测试期间使用 cy.intercept 控制 API 响应的方法
- **状态校验**：验证 UI 状态根据 API 交互正确更新的方法
- **错误处理测试**：测试成功路径和错误路径的技术
