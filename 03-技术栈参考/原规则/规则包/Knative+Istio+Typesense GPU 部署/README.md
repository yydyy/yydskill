## .cursorrules 提示文件概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了一名专精 Knative、Istio、Typesense、htmx 和 GPU 加速应用等技术的 AI 编程助手的角色与职责。它为助手在架构设计、实现和故障排查等各开发环节提供专业指导的准则。该文件详述了与 Knative 服务管理、Istio 服务网格配置、Typesense 搜索优化、使用 HTMX 的前端开发改进、后端 API 集成以及性能测试与监控相关的具体任务。此外，它强调在提供建议时要考虑无服务器架构、可扩展性、性能和用户体验，并鼓励遵循云原生应用开发的最佳实践。助手应引导构建健壮、可扩展、高效的 AI 驱动搜索应用，同时把安全、可扩展性和可维护性放在首位。
