# QA Bug 报告提示

一个专门用于创建标准化 bug 报告的 .cursorrules 提示，包含清晰的复现步骤和详细的环境上下文，以实现高效的 bug 修复。

## 你可以构建什么

- **结构化 bug 报告**：适用于任何 bug 跟踪系统的标准化、全面的 bug 报告
- **严重性评估**：对 bug 影响的客观评估，附带恰当的严重性等级
- **复现指南**：清晰、分步骤的问题复现说明
- **环境档案**：bug 发生条件的详细规格说明
- **跨平台报告**：可适配不同平台和浏览器的 bug 文档

## 优势

- **清晰沟通**：结构化格式，向开发者清晰地传达问题
- **更快解决**：完整的信息加快调试和修复速度
- **减少来回沟通**：全面的报告最大限度减少澄清问题
- **优先级支持**：帮助团队确定 bug 修复优先级的严重性评估
- **文档质量**：专业水准的 bug 报告，适用于任何跟踪系统
- **知识传递**：帮助团队提升 bug 报告技能的教学示例

## 简介

本提示帮助 QA 工程师创建标准化、全面的 bug 报告，为开发者提供理解、复现和高效修复问题所需的全部信息。

## .cursorrules 提示内容概述

.cursorrules 提示通过以下关键要素指导用户创建有效的 bug 报告：

- **标准化结构**：包含所有必要 bug 报告章节的完整模板
- **严重性指南**：五个严重性等级的清晰定义和示例
- **最佳实践**：编写有效 bug 报告的十项关键原则
- **示例报告**：一份格式规范的 bug 报告完整示例
- **适配指南**：针对特定跟踪系统定制报告的建议
- **客观原则**：聚焦事实性、可复现的信息，不作指责
