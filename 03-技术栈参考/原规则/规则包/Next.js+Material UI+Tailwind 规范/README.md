## .cursorrules 提示内容概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了一个名为 "Portfolio2" 的 Next.js 项目的配置。它指定使用 TypeScript 和 Tailwind CSS，但选择不使用 ESLint，也不自定义默认的导入别名。项目结构包含 `src/` 目录和 App Router。文件列出了项目所需的一整套关键依赖，例如 UI 组件、样式、身份验证和数据库客户端相关的包。核心依赖包括 Material UI、Tailwind CSS、Prisma 和 Next.js。此外，还包含开发环境所需的相关 devDependencies，如类型定义和 PostCSS。
