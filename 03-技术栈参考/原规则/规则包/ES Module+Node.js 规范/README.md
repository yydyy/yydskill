## 你可以构建什么
敏捷项目管理工具：帮助团队用敏捷方法规划、管理和执行项目的 Web 应用，可对任务排定优先级、跟踪进度并提供分析以优化工作流。模块化代码仓库平台：类似 GitHub 的平台，鼓励开发者创建、分享和协作模块化且 DRY 的组件，提供重构建议并推广最新的 ES 与 Node.js 特性。性能与安全测试套件：自动评估代码性能与安全并给出改进建议的工具，在开发过程中识别冗余代码和潜在安全漏洞。ES Module 转换工具：帮助开发者把遗留代码库重构为 ES modules、确保使用最新 JS 特性的服务，在转换过程中提供校验与纠错。基于版本的交互式文档生成器：根据用户选择的详细程度（V0 到 V3）生成从简明到详尽文档的工具，解释代码各部分并突出所用的模块化与敏捷实践。AI 驱动的代码重构建议插件：在你输入时给出代码改进与重构建议的代码编辑器扩展，聚焦性能、模块化和安全增强。任务优先级 AI 助手：集成主流项目管理软件、帮助团队拆解任务并有效排定优先级、确保敏捷工作流的 AI 工具。ES 与 Node.js 学习平台：提供教程和交互式编程挑战、教授最新 ES 与 Node.js 特性的教育平台，鼓励用户练习最佳编码实践。注释生成/优化工具：帮助开发者编写有意义注释来描述代码用途的插件，尤其适用于操作意图不明显或使用非常见库的代码段。代码历史对比器：对比代码库不同版本、就性能、安全和模块化随时间改进情况提供洞察的工具。

## 简介
希望用现代 ES 与 Node.js 特性构建高效、模块化、安全的 JavaScript 应用的开发者，可通过构建面向任务、经过重构且注释完善的代码结构而受益。

## .cursorrules 提示词概述
.cursorrules 文件概述了软件开发实践指南，强调模块化、性能和安全，同时遵循敏捷方法。它鼓励把任务拆解为有优先级的步骤，并按详细程度（V0 到 V3）规定回复的优先内容。编码方面，它建议使用 ES module 语法，推荐使用最新的 ES 与 Node.js 特性进行重构，并在必要时添加 TODO 注释。注释应澄清代码中不明显的操作，描述目的而非效果。文件强调纠正错误时不要道歉。
