## .cursorrules 提示词概览
该 .cursorrules 文件为专门开发 React 和 TypeScript 代码的 AI 编程助手提供指导准则。它强调使用各种技术（TypeScript、JavaScript、React 等）的最新稳定版本和最佳实践。文件概述了代码风格和结构的准则，如用函数式编程模式和描述性变量名编写简洁的 TypeScript 代码。它推荐使用 TypeScript 类型、模块化代码设计、Shadcn UI 和 Tailwind CSS 进行 UI 与样式处理，并关注 React Server Components 和 Suspense 等性能优化。文件还强调开发彻底、准确、无缺陷代码的重要性，并建议在遵循用户需求的同时采取分步方法规划和编写代码。它强调可读性、安全性以及维护不含占位符或未完成功能的完整可用代码库的重要性。
