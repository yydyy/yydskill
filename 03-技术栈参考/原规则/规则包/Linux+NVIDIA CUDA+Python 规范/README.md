# Linux NVIDIA CUDA Python .cursorrules 提示文件

作者：Shaun Prince

## 可以构建什么
AI 模型压缩服务：一项云服务，允许用户上传 AI 模型，自动对其进行量化，并提供优化后更小的版本供下载。该服务免除了对本地硬件和模型量化专业知识的需求。模型量化 GUI 工具：一个图形用户界面应用，简化 Hugging Face 模型的量化流程。它面向不习惯使用终端命令或脚本的用户，提供可视化的工作流。量化即服务平台：一个订阅制平台，面向拥有需要优化的 AI 模型的企业。它提供批量处理、量化任务实时监控以及与现有企业基础设施集成等功能。量化最佳实践库：一个精心策划的在线资源，提供 AI 模型量化的指南、教程、案例研究和工具。对于需要理解模型量化细节与技术的从业者来说，它是首选门户。Hugging Face 模型兼容性检查器：一个评估 Hugging Face 模型与各种硬件配置兼容性并推荐合适量化策略的工具。它帮助开发者确保模型在不同 GPU 上以最优状态运行。分布式模型量化框架：一个开源框架，支持跨多个节点的分布式量化，缩短大型模型的处理时间。它对拥有多个服务器但希望更高效利用时间的组织尤其有用。模型量化交互式教程：一个面向初学者的交互式 Web 教程，引导他们完成 Hugging Face 上 AI 模型的量化流程。可包含视频演示和代码示例。模型量化分析仪表板：一个提供量化过程洞察的工具，如运行时统计、成功率，以及基于以往量化尝试给出的改进建议。量化误差可视化工具：一个帮助可视化模型量化时出现的误差与性能权衡的应用，协助开发者在量化策略的取舍上做出明智决策。AI 模型硬件兼容性数据库：一个详尽的数据库，列出各种 AI 模型及其与不同类型硬件和量化工具的兼容性，并建立索引，方便寻求优化部署效率的开发者查阅。

## 简介
专注于机器学习模型部署的开发者将从中受益，并可构建一个精简的工具来自动化模型量化，以便在 Linux 服务器上高效部署。

## .cursorrules 提示概览
该 .cursorrules 文件定义了由 SolidRusT Networks 开发的名为 'srt-model-quantizing' 的项目。该应用的目的是简化从 Hugging Face 下载、量化并上传模型到兼容仓库的流程。它以简洁为设计目标，让用户能用 Python 或 Bash 在 Linux 服务器上轻松搭建和运行应用。它同时支持 Nvidia CUDA 和 AMD ROCm GPU，尽管不同硬件可能需要相应调整。开发原则强调效率、健壮性和全面的文档。项目还注重保持简洁、提升代码质量，并使用开发对齐 markdown 文件跟踪进度。通过收集反馈、提出用户友好的改进建议以及清晰记录所做的任何变更，鼓励持续改进。
