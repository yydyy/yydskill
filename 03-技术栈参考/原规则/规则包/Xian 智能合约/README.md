# Xian 智能合约（Xian Smart Contracts）

## 简介（Introduction）
Xian 是一个现代区块链平台，让开发者可以用原生 Python 编写智能合约。不同于其他需要专门语言或转译的区块链平台，Xian 支持直接用 Python 编码，让全球数百万 Python 开发者都能轻松上手。

## Xian 的用途（What Xian Can Be Used For）

- **DeFi 应用**：创建去中心化金融应用，包括代币兑换、借贷协议和收益耕作平台
- **NFT 与数字藏品**：轻松开发 NFT 市场和数字藏品平台
- **DAO**：构建带有投票机制和资金管理的去中心化自治组织
- **供应链解决方案**：创建透明的供应链跟踪系统
- **身份管理**：开发自我主权身份（self-sovereign identity）解决方案
- **游戏**：构建带有游戏内经济的区块链游戏

## 核心特性（Key Features）

- **原生 Python 智能合约**：用纯 Python 编写合约，无需转译
- **事件驱动架构**：使用事件跟踪状态变更并触发动作
- **丰富的标准库**：提供加密函数、哈希工具等
- **全面的测试框架**：用熟悉的 Python unittest 模式测试合约
- **状态管理**：通过 Variables 和 Hashes 实现简洁而强大的状态管理

## 快速开始（Getting Started）

要在 Xian 上开始开发：

1. 搭建 Python 3.11+ 的开发环境
2. 
   1. 克隆 [xian-contracting](https://github.com/xian-network/xian-contracting)
   2. 安装 Xian Contracting `cd xian-contracting && pip install -e ./`
3. 使用提供的[模板](https://github.com/xian-network/xian-contracts)创建你的第一个智能合约
4. 使用测试框架测试你的合约
5. 部署到 Xian 网络
