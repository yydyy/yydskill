## 你可以构建什么
自动化代码审查工具：一个根据提供的规则自动审查代码并标记潜在问题的应用。它确保代码遵循最佳实践，例如避免臆测、核实信息，以及精确地逐文件修改。协作编码平台：一个在强制执行编码规则的同时允许多位开发者同时参与项目的平台。它对代码更改提供实时反馈，重点是保留现有代码、避免不必要的更新。代码文档助手：一个帮助开发者编写更好文档的工具，不写摘要或不必要的确认。它引导用户提供清晰、有依据的指令和文档。无差错编码导师：一个教育服务，按照提供的规则通过实时反馈训练开发者的最佳编码实践。它杜绝猜测、不必要的确认和空白字符建议等坏习惯。代码一致性检查器：一个扫描代码库的工具，确保一致性和对编码标准的遵守，例如代码注释中不道歉、不请求确认，并使用单块编辑保持清晰。版本控制增强器：一个版本控制系统插件，在提交过程中高亮显示任何偏离编码规则之处，并在更改推送到仓库前促使遵守规则。质量保证插件：一个 IDE 插件，提供与所列规则一致的质量检查。它给出建议以维护代码完整性和开发效率，不做不必要的更改或虚构。真实文件链接器：一个服务，自动将代码文档链接到实际文件而不是 x.md 之类的占位符，确保开发者获得准确的资源。

## 简介
开发代码审查工具的开发者可以使用本提示构建一个工具，自动就代码对指定指南的遵守情况提供反馈。

## .cursorrules 提示内容概述
.cursorrules 文件概述了一套可定制的规则，用于指导开发者修改代码或文档。每条规则使用 regex 定义一个模式来匹配特定词语或短语，并提供一条消息来建议或提醒开发者最佳实践。这些规则涵盖多个方面，如核实信息、避免不必要的注释或确认、保留现有代码，以及确保编辑简洁。文件旨在通过在开发和文档过程中执行这些指南，维持代码质量、清晰度和效率。
