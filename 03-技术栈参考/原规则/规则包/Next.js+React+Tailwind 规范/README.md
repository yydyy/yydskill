组件库生成器：创建一个工具，自动化生成基于 Shadcn UI、Tailwind 和 TypeScript 的组件库。开发者可以输入组件规格，获得组织良好、带样式、可直接使用的代码。响应式 UI 设计工具：开发一个 Web 应用，让用户使用 Tailwind 和 Shadcn UI 设计和可视化响应式界面。用户可以实时预览设计在各种设备尺寸下的效果，并导出 TypeScript 代码。TypeScript 项目代码质量分析器：构建一个应用，分析 TypeScript 代码库，确保遵守编码风格、命名约定和 UI 指南等最佳实践。它还可以提供性能和 web vitals 方面的优化建议。Node.js 服务端-客户端架构检查器：一个审查 Node.js 项目、评估服务端与客户端组件分布的应用，在 Next.js 环境中提出性能和可扩展性方面的优化建议。懒加载和图片优化服务：一个插件或扩展，为 Web 项目自动实现懒加载和图片优化，确保对图片使用懒加载技术并采用 WebP 格式。动态导入调度器：为 Web 应用创建一个调度工具，识别非关键组件并建议动态导入的最佳时机，在不影响用户体验的情况下提升性能。'Nuqs' 状态管理集成器：开发一个库，将 'nuqs' URL 搜索参数状态管理无缝集成到 Next.js 应用中，用最佳实践指导开发者进行有效的状态管理。Tailwind CSS 定制平台：一个允许开发者创建和定制 Tailwind CSS 主题的平台，提供可视化工具、代码示例和导出选项，专为 TypeScript 项目量身打造。Next.js 项目结构模板：提供一个模板或生成器，用于创建采用推荐的 /src/app 和 /src/components 目录结构的新 Next.js 项目，确保架构组织有序且可扩展。基于 React Hooks 的 FRAMER Motion 动画库：构建一个库，将预先设计的 Framer Motion 动画封装在 React hooks 中，简化项目中高级动画的实现。

## 简介
使用 TypeScript、React 和 Tailwind 构建可扩展、组织良好的 Next.js 项目的开发者，将从本提示的指南中受益，以维护结构、性能和可读性。

## .cursorrules 提示概览
该 .cursorrules 文件概述了使用 Node.js、Next.js App Router、React、Shadcn UI、Tailwind 和 Framer Motion 的 TypeScript 项目的编码约定与组织最佳实践。它强调简洁、技术性的编码风格，偏好函数式与声明式编程模式。文件建议使用描述性命名约定、用 TypeScript interface 而非 type，并避免某些模式（如 enum）。它强调文件结构、用 Tailwind CSS 进行响应式 UI 设计，以及限制客户端交互、采用 server components 等性能优化技术的重要性。组件组织建议在结构化的目录布局中按类型或按特性划分，以增强模块化和可扩展性。项目结构强调放在 /src 目录下，以保持清晰并符合行业标准。
