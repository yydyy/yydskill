## 简介
使用 DragonRuby Game Toolkit 的 Ruby 游戏开发者可通过遵守这些编码标准与约定，创建可扩展、可维护的视频游戏应用。

## .cursorrules 提示文件概述
.cursorrules 文件旨在指导资深游戏开发者使用 DragonRuby Game Toolkit 编写 Ruby 代码。它强调编写简洁地道的 Ruby 代码、遵守 Ruby 与 DragonRuby 约定并遵循最佳实践。文件概述了代码风格与结构，推荐面向对象与函数式编程模式、迭代、模块化，以及使用描述性的变量与方法名。它还规定了命名约定：文件、方法与变量使用 snake_case，类与模块使用 CamelCase。语法与格式应遵循 Ruby Style Guide，例如使用 Ruby 富表现力的语法、无插值的字符串使用单引号。错误处理应在异常情形使用异常并做恰当的错误日志。此外，文件建议遵循官方 DragonRuby Game Toolkit 指南，以在各组件中落实最佳实践。
