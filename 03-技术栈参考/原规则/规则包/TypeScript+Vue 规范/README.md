## .cursorrules 提示文件概述
.cursorrules 文件为聚焦 Vue.js 项目的 TypeScript 开发提供一套指南与约定。它鼓励简洁、专业的编码实践，偏好函数式与声明式编程模式，避免不必要的重复与类结构。文件强调使用 Bun 原生模块与 TypeScript 接口、避免 enum，并使用描述性变量名。它详述了目录命名约定，并建议优先使用具名导出。语法与格式规则包括纯函数使用 `function` 关键字、条件语句简洁化。错误处理方面，建议提前返回、使用 Zod 做校验以及恰当的错误日志。UI 与样式采用 Vue.js 单文件组件配合 Tailwind CSS，并遵循移动优先方法。性能优化技术包括用 WebP 优化图片、懒加载以及优化 Web Vitals。文件还建议使用 vueuse 函数、力求完整测试覆盖，并尽可能采用浏览器原生实现。它强调使用 Composition API 与 setup script，并建议在适当处与 Vue.js 文档保持一致。
