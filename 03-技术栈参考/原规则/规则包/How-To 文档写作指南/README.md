# How-To 文档写作指南（How-To Documentation Prompt）

一个专门用于创建清晰、用户友好的「操作指南（How To）」文档的 .cursorrules 提示词，帮助非技术用户理解软件功能。

## 你可以构建什么

- **用户指南**：使用应用功能的分步说明
- **培训材料**：帮助新用户上手你的软件的文档
- **知识库文章**：面向常见用户问题的可搜索帮助内容
- **支持文档**：故障排查指南和使用说明
- **平台专属指南**：针对不同设备或平台量身定制的说明

## 优势

- **易懂的文档**：把技术概念转化为简单、用户友好的语言
- **统一的格式**：标准化的结构，易于遵循和理解
- **更好的用户体验**：清晰的说明，减少支持工单和用户困扰
- **多样的输出格式**：内容适用于各种文档平台（Google Docs、Microsoft Word、Atlassian 等）
- **技术转译**：把技术测试脚本或开发者笔记转换为用户友好的指南
- **包含故障排查**：将常见问题和解决办法纳入文档

## 简介

这一提示词帮助技术写作者和开发者创建高质量的「操作指南」文档，弥合技术功能与用户理解之间的鸿沟，让所有用户都能轻松使用软件功能。

## .cursorrules 提示文件概述

`.cursorrules` 提示词指导技术写作者创建有效的「操作指南」文档，包含以下关键要素：

- **文档聚焦**：用用户友好的语言编写分步说明的指南
- **最佳实践**：清晰有效文档的八条基本实践
- **文档结构**：包含标题、简介、前置条件、步骤和故障排查的标准化格式
- **示例文档**：Markdown 格式的完整「操作指南」文档详细示例
- **技术转换**：把技术脚本或用户故事转换为用户友好文档的流程
- **简化语言**：强调使用非技术术语和清晰的解释
- **视觉引用**：以用户所见方式引用 UI 元素的技巧
