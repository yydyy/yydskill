## .cursorrules 提示内容概述
.cursorrules 文件概述了使用 Svelte 5、SvelteKit 和 TypeScript 开发 Web 应用的指南和约定。它强调使用简洁、技术性强的代码、高效的服务端渲染（SSR）和静态站点生成（SSG），以及性能优化。文件提供了代码风格、结构、命名约定和状态管理的具体规则，包括使用 Svelte 特有的构造（如响应式状态声明）。它还涵盖使用 Tailwind CSS 和 Shadcn 组件的 UI 样式、路由、表单、基于 Paraglide.js 的国际化，以及无障碍。鼓励开发者遵循 SvelteKit 的项目结构、利用 Svelte 的 SSR 能力，并优先考虑 Web 性能指标。文件还包含详尽的文档链接供进一步参考。
