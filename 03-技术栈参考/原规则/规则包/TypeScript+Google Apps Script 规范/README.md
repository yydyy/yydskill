# TypeScript Google Apps Script .cursorrules 提示文件

作者：Shreyas Prakash

## 你可以构建什么
Google Sheets 自动化：使用 TypeScript 和 Google Apps Script 为 Google Sheets 开发自定义函数和宏。实现数据校验、自定义格式和复杂计算。

Gmail 加载项：创建一个提升邮件效率的 Gmail 加载项。使用 TypeScript 构建邮件分类、自动回复或与外部服务集成等功能。

日历管理工具：构建一个与 Google Calendar API 交互的工具，用于管理日程、发送通知并分析日程安排模式。

文档处理系统：使用 Google Apps Script 和 TypeScript 开发一个系统，自动化创建、修改和整理 Google Docs。

表单回复分析器：创建一个脚本，处理 Google Forms 回复、生成报告，并根据用户输入发送自动跟进邮件。

Drive 文件管理器：为 Google Drive 构建一个文件管理系统，整理文件、设置权限并生成使用报告。

Classroom 作业追踪器：开发一个 Google Classroom 加载项，使用 TypeScript 和 Google Apps Script 帮助教师跟踪作业、批改提交并提供反馈。

Slides 演示文稿生成器：创建一个工具，基于 Sheets 或其他来源的数据自动生成 Google Slides 演示文稿。

Meet 出勤追踪器：构建一个与 Google Meet 集成的系统，跟踪出勤情况、生成报告并向参与者发送跟进邮件。

Sites 内容管理系统：为 Google Sites 开发一个 CMS，使用 TypeScript 和 Google Apps Script 更轻松地创建、更新和管理内容。

## 优势
- TypeScript 带来的类型安全和代码质量提升
- 与 Google Workspace 应用的无缝集成
- 通过自动化重复任务提升生产力
- 借助 Google 强大的 API 扩展功能

## 简介
精通 TypeScript 和 Google Apps Script 的开发者可以为 Google Workspace 应用创建强大的加载项和自动化工具，在功能和可维护性上都达到优化。

## .cursorrules 提示内容概述
.cursorrules 文件为使用 Google Apps Script 和 clasp 开发 TypeScript 应用提供指南。它推荐使用 npm 作为包管理器，并强调模块化设计和详尽文档的重要性。文件提倡使用 TypeScript 的接口和类型注解等特性来提升代码可靠性。它指定了 Google Apps Script 服务和 API 的使用，并鼓励遵循 Google 的脚本开发最佳实践。文件还就通过高效使用配额和资源进行性能优化给出建议，并强调脚本应用中错误处理和日志记录的重要性。
