## .cursorrules 提示文件概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了数据分析、可视化和 Jupyter Notebook 开发的最佳实践与原则，聚焦 pandas、matplotlib、seaborn 和 numpy 等 Python 库。它强调给出简洁而专业的回复、提供准确的 Python 示例，并推动数据分析工作流的可读性和可复现性。它倡导函数式编程、向量化操作和描述性变量名。该文件还提供了使用 pandas 进行数据操作、用 matplotlib 和 seaborn 做可视化以及组织 Jupyter Notebook 的指导。它包含错误处理、数据校验和性能优化方面的建议，并列出了 pandas、numpy 和 scikit-learn 等核心依赖。它鼓励从数据探索和文档记录开始分析，同时使用 git 等版本控制系统。
