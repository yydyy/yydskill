## 简介
WordPress 开发者可以创建一个插件：使用 Guzzle 集成外部 API，添加自定义 WP REST 端点，并引入 Gutenberg 区块，同时遵循 WordPress 编码标准、优化代码可读性。

## .cursorrules 提示内容概述
.cursorrules 文件为开发 WordPress 插件提供指南，该插件包含基于 Guzzle 的 HTTP 客户端、WP REST 端点扩展和新的 Gutenberg 编辑器区块。它强调对 PHP、JavaScript 和 TypeScript 使用 WordPress 编码标准，并且相比 JavaScript 更偏好 TypeScript。文件提倡函数式编程范式和组合优于继承，同时确保与 WordPress 生态系统最佳实践保持一致。此外，它强调优化代码可读性以及在 PHP 代码中使用类型提示的重要性。
