## 你可以构建什么
在线体育竞猜池管理平台：开发一款综合 Web 应用，用户可加入体育竞猜池、提交请求，并由管理员批准其参赛条目。通过严格遵守封装在后端逻辑中的规则与准则来确保公平竞技。游戏化投注体验：创建一个让用户以更具互动性的方式参与体育竞猜池的平台，提供游戏化界面用于提交选择、追踪得分与管理条目，提升用户参与度与体验。竞猜池管理后台仪表板：用 React.js 构建管理面板，让竞猜池管理员轻松管理用户请求、批准或拒绝条目、追踪支付状态，并在批准后自动创建条目，配备直观导航与实时更新。安全的体育投注支付网关：实现一个集成支付系统，采用安全、经过校验的方法并遵循支付追踪最佳实践，确保用户能够保密且高效地为竞猜池条目付款。实时条目追踪与计分系统：提供一个实时系统，用户可监控自己条目的状态、在比赛后查看实时计分更新并全面查看排名，让投注过程透明且更具参与感。全面的用户洞察与分析：开发一款分析用户数据（包括选择与表现）的工具，提供洞察与统计数据，帮助用户改进未来的竞猜池策略与决策过程。基于伪代码的开发工具包：提供一个强调伪代码驱动开发的工具包，帮助开发者在正式编码之前准确高效地规划 API 端点与业务逻辑。面向体育竞猜池应用的 RESTful API：创建一个稳健的 RESTful API，处理用户认证、请求提交、条目管理与计分系统，遵循行业最佳实践确保数据传输与管理安全高效。互动式用户历史与归档：开发一项功能，让用户查看并分析自己的历史数据，包括过往选择与成就，形成个人体育投注归档，助力个人追踪与历史表现评估。竞猜池参与者社区论坛：为同一竞猜池内的用户开设讨论板，营造社区氛围，让参与者分享见解、讨论策略，共享体育投注的乐趣。

## 简介
构建体育竞猜池管理平台的开发者将受益于本提示：打造结构化的后端系统，包含用户认证、细致的选择管理与管理端控制界面。

## .cursorrules 提示文件概述
.cursorrules 文件概述了使用 Node.js、MongoDB、React.js 与 Git 等指定技术开发竞猜池类应用的结构化方法。它强调精确遵守用户需求，尤其是用户流程与游戏规则。文件建议先写伪代码来规划功能实现，确保代码安全高效、遵循 RESTful API 最佳实践，并实现错误处理与输入校验。文件详述了关键用户流程与管理流程，如条目与选择管理、计分与结果查看；并给出限制用户请求、追踪条目、管理支付与状态流转、开发请求管理后台界面的指南。部署方面建议可选的 Docker 部署。
