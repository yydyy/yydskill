## 简介
专注 Solidity 安全的智能合约开发者可以借助本提示词，运用 OpenZeppelin 等最佳实践与工具创建安全、高效、文档完善的区块链应用，在优化性能的同时大幅减少漏洞。

## .cursorrules 提示词概述
.cursorrules 文件确立了一套开发和保障 Solidity 智能合约安全的指南。它强调简洁准确的代码实现，鼓励拥抱新技术，并概述了多种 Solidity 开发最佳实践，包括使用特定编码模式和工具来增强智能合约的安全性、可读性和可维护性，例如使用显式函数可见性修饰符、为状态变更实现事件、遵循 Checks-Effects-Interactions 模式。文件还强调通过全面的测试策略和定期安全审计来保障测试与质量。此外，它涉及面向 gas 效率的性能优化，并提供了融入 Hardhat 等工具的开发工作流。文件倡导文档最佳实践，重点维护清晰且保持更新的智能合约文档。
