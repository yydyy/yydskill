## .cursorrules 提示文件概述
`.cursorrules` 文件为使用 JavaScript、TypeScript 和 Astro 框架构建可扩展 Web 应用的开发者提供指南和最佳实践。它强调编写简洁准确的技术回复、优先采用静态生成，并以最少的 JavaScript 优化性能。文件概述了 Astro 中推荐的项目结构、组件开发、路由和内容管理实践。它强调使用作用域样式、性能优化技术、数据获取、SEO 考量、集成和部署实践。文件还给出了 Tailwind CSS 样式、实现测试、确保可访问性和维护关键约定的最佳实践。同时推荐了性能指标和监控工具，以确保 Web 应用性能最优。鼓励开发者参考 Astro 官方文档获取详细指导。
