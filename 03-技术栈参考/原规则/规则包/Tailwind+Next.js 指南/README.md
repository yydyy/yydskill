# Tailwind CSS Next.js 指南（.cursorrules prompt 文件）

作者：brolag

## 可以构建的内容（What You Can Build）
组件库网站 - 一个提供可复用、模块化组件集合的网站，使用 TailwindCSS 和 DaisyUI 设计样式，具备严格的 TypeScript 集成和详尽的文档。每个组件都包含具体的样式类、TypeScript 接口、响应式设计指南、状态管理 hooks 和无障碍特性。Next.js 脚手架生成器 - 一款生成 Next.js 项目的工具，预先配置好动态路由、数据获取方法（getServerSideProps、getStaticProps）、增量静态再生、通过 next/image 优化的图片以及严格的 TypeScript 设置。它包含 TailwindCSS 与 DaisyUI 的样式集成，以及用于代码格式化和 lint 的 Biome。区块链 DApp 入门套件 - 一个基于 StarkNet 和 Cairo 开发去中心化应用的入门套件。它集中管理区块链连接，包含健壮的错误处理，并提供带有完整文档的交易管理 hooks。采用模块化架构，使用 TypeScript、TailwindCSS 和 DaisyUI 构建 UI 组件。TailwindCSS 设计令牌管理器 - 一个用于管理和自定义 tailwind.config.js 中设计令牌的 Web 应用，让用户在各组件间创建一致的样式。它提供可视化界面来定义响应式变体和自定义 DaisyUI 组件，同时确保与 Next.js 集成并严格使用 TypeScript。React 组件自动化测试框架 - 一款专门为使用 TailwindCSS 和 DaisyUI 样式的 React 组件运行自动化测试（单元、集成、e2e）的工具。包含针对 prop 校验和结构组织的 TypeScript 支持，通过有意义的测试确保全面的测试覆盖。Next.js SEO 优化工具包 - 一个帮助 Next.js 开发者优化应用 SEO 的插件或工具。它提供关于动态数据获取、静态属性、响应式图片和渐进增强的洞见，并说明其对 TailwindCSS/DaisyUI 样式的影响。AI 驱动的代码审查助手 - 一项提供智能代码审查建议的服务，聚焦 Next.js、TypeScript、TailwindCSS、Biome 规则和 DaisyUI 组件。它确保遵循开发最佳实践，包括 prop 校验、状态管理和响应式设计。与 Biome 的持续部署集成 - 一项 CI/CD 服务，将 Biome 的代码格式化、lint 和 pre-commit 检查集成到部署流水线中。它确保使用 TypeScript、Next.js 和 TailwindCSS/DaisyUI 的项目保持代码质量与风格一致。交互式 TailwindCSS/DaisyUI 沙盒 - 一个开发者可以实时试验 TailwindCSS 工具类和 DaisyUI 组件的在线工具。它提供实时预览、响应式设计检查和组件代码导出选项，并给出 TypeScript 类型建议。Next.js 项目性能优化分析器 - 一款分析 Next.js 应用性能瓶颈的诊断工具。它提供关于用 next/image 优化图片处理、高效使用动态路由以及利用 ISR 的洞见，并附有 TailwindCSS 样式优化的详细报告。

## 优点（Benefits）
强制使用 TypeScript 的高级特性与运行时检查，强调以强类型接口代替 'any'，以获得健壮且可维护的代码。鼓励在全项目中采用 Biome 以保持一致的代码格式化和 lint，并与 CI/CD 流水线集成实现自动检查。促进 Next.js 和 TailwindCSS 框架内的模块化与关注点分离，利用 DaisyUI 高效开发组件并优化性能。

## 简介（Synopsis）
正在构建 Next.js Web 应用、使用 Tailwind CSS 和 DaisyUI 组件、并用 TypeScript 和 Starknet 进行区块链交互的开发者，将从本 prompt 中受益，用它创建模块化、响应式且经过优化的组件。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件为使用 React、TypeScript、Next.js、TailwindCSS、DaisyUI 和 Starknet React 的开发者提供了全面的指南和最佳实践。它概述了 prompt 生成、通用组件创建和开发流程的规则，强调可复用性、模块化和一致的编码标准。具体规则包括：使用 TailwindCSS 和 DaisyUI 进行样式设计、运用 TypeScript 的高级特性、充分利用 Next.js 的能力，以及用 Starknet React 管理区块链连接。它还强调通过 Biome 进行格式化和 lint 来保证代码质量，并鼓励充分的测试与文档编写。该文件提供了一种结构化的方法，确保高效、可维护、高质量的代码产出。
