## .cursorrules 提示词概述
.cursorrules 文件为使用 Solidity、TypeScript、Node.js、Next.js、React 及多种 UI 与样式框架的开发者制定了全面指南。它强调用函数式、声明式编程范式编写简洁准确的 TypeScript 代码。核心原则包括模块复用、描述性命名约定，以及偏好具名导出。文件给出了 JavaScript/TypeScript 的具体结构与语法建议，强制健壮的错误处理，并推荐在 UI 开发中使用特定的工具和库。对于 React/Next.js 应用，它规定使用函数组件、移动优先的响应式设计，以及状态管理和错误处理的最佳实践。此外还强调 Server Actions 的约定、使用 Zod 做校验，以及性能优化与错误处理策略。文件还强调遵循 Next.js 文档中关于数据获取与渲染的最佳实践。
