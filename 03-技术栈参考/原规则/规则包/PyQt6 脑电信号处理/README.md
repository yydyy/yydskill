# PyQt6 EEG 处理 .cursorrules 提示文件

作者：Ernie Pedapati

## 可以构建什么
脑电分析与可视化应用：开发一个应用，为研究人员和神经科医生提供出色的 EEG 数据可视化，集成高级 PyQt6 特性实现用户友好的控制与交互。实时脑电监测软件：创建一个用于实时 EEG 信号处理和监测的软件，使用优化的算法和 PyQt6 界面，将数据无缝推送给医疗工作者并清晰呈现数据。脑电教学工具：设计一个互动教学平台，利用真实 EEG 数据向学生教授神经科学和信号处理，融入引人入胜的 PyQt6 UI 元素和详细的数据可视化。远程脑电协作服务：构建一个 Web 服务，让研究团队实时协作 EEG 数据集，确保数据安全共享，并可与 REDCap 等现有数据库集成。可定制的脑电分析框架：提供一个面向学术界和工业界的模块化 EEG 分析框架，允许用户将自己的处理算法与基于 PyQt6 的强大界面集成。脑电数据管理系统：开发一个数据管理解决方案，组织和保护大型 EEG 数据集，具备直观的工作流和文件处理方式，并集成云服务以实现可扩展性。移动端脑电查看应用：创建一个跨平台移动应用查看和交互 EEG 数据，利用自适应的 PyQt6 设计适配小屏幕，确保在各种设备上流畅运行。AI 驱动的脑电助手：构建一个分析 EEG 数据以提供诊断建议和洞察的 AI 助手，通过高级 PyQt6 图形组件提供信息丰富的界面。脑电工作流自动化工具：设计一个自动化常见 EEG 处理任务的工具以提高研究效率，具备自定义工作流和自动化脚本，通过 PyQt6 设计的仪表板进行管理。脑电文件格式转换工具：开发一个在不同标准格式之间转换 EEG 数据的实用工具，确保与各种软件兼容，并提供易于使用的 PyQt6 用户界面进行文件操作。

## .cursorrules 提示概览
该 .cursorrules 文件定义了旨在协助或充当资深 Python 程序员的 AI 系统的角色与职责。重点在于 PyQt6、EEG 信号处理和工作流优化方面的专业能力。主要职责包括用 PyQt6 创建精致的用户界面、开发 EEG 数据处理算法、优化工作流效率，并通过最佳实践确保高代码质量。文件还概述了性能优化、与外部工具的无缝集成以及稳健的 UI/UX 设计原则的必要性。此外，它提供了开发 EEG 处理应用的实现指引，强调简洁的 UI、模块化架构和全面的测试。
