# 面向 Cursor AI 的 C++ 编程指南（C++ Programming Guidelines for Cursor AI）

本 `.cursorrules` 文件为使用 Cursor AI 进行 C++ 开发提供全面的指南和最佳实践。它通过统一命名约定、编码模式以及 C++ 编程的其他重要方面，帮助在 C++ 项目中保持一致的高质量代码。

## 文件匹配模式

本 `.cursorrules` 文件设计用于匹配以下文件模式：

- `*.cpp` - C++ 源文件
- `*.h` - C/C++ 头文件
- `*.hpp` - C++ 头文件（替代扩展名）
- `*.cxx` - C++ 源文件（替代扩展名）
- `*.cc` - C++ 源文件（替代扩展名）
- `*.c` - C 源文件（项目混合使用 C 与 C++ 时）
- `CMakeLists.txt` - CMake 构建配置文件
- `*.cmake` - CMake 脚本文件
- `Makefile` - Make 构建文件

## 主要特性

- 变量、函数、类和文件的全面命名约定
- 函数设计与实现的最佳实践
- 类结构与组织指南
- 使用现代 C++ 特性的内存管理建议
- 项目结构组织
- 标准库使用指南
- 并发与多线程最佳实践

## 使用方法

将本 `.cursorrules` 文件放在 C++ 项目根目录，以确保 Cursor AI 依据这些指南生成和修改 C++ 代码。
