# Jest 单元测试提示

一个专门的 .cursorrules 提示，用于使用 Jest 创建全面的单元测试并支持 TypeScript。

## 可以构建什么

- **单元测试套件**：针对关键业务逻辑和工具函数的聚焦测试
- **基于 Mock 的测试**：正确地将代码与外部依赖隔离的测试
- **数据驱动测试**：在多种数据场景下验证功能的测试
- **TypeScript 测试**：带正确定义的 interface 的强类型测试
- **边界情况覆盖**：处理意外输入和边界条件的测试

## 优势

- **正确的依赖隔离**：在导入之前对依赖进行一致的 mock
- **完整的 TypeScript 支持**：对被测函数和 mock 依赖提供完整的类型安全
- **全面的测试覆盖**：聚焦业务逻辑与各种数据场景
- **有组织的测试结构**：在描述性的 describe 块中对测试进行逻辑分组
- **边界情况检测**：测试 null、undefined 和意外类型等常引发 bug 的情况
- **可维护的测试套件**：每个文件只保留有限数量的聚焦测试，更易维护

## 简介

本提示帮助开发者用 Jest 创建高质量的单元测试，聚焦关键功能，同时确保正确 mock 依赖、覆盖全面的数据场景和边界情况。

## .cursorrules 提示概览

该 .cursorrules 提示指导开发者使用 Jest 创建有效的单元测试，包含以下关键要素：

- **TypeScript 检测**：自动检测并适配项目中的 TypeScript 使用情况
- **依赖 Mock**：使用 Jest 的 mock 函数在导入之前正确 mock 依赖的指南
- **最佳实践**：单元测试的八项基本实践，包括聚焦关键功能、数据场景和边界情况
- **示例测试模式**：提供 JavaScript 和 TypeScript 的详细单元测试示例，结构规范
- **可维护的方法**：每个文件只写少量高价值的测试
- **测试组织**：使用 describe/it 块并以描述性名称组织测试
- **AAA 模式**：使用 Arrange-Act-Assert 模式的示例，让测试结构清晰
