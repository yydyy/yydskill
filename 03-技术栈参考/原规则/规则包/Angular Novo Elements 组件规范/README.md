# Angular Novo Elements（.cursorrules prompt 文件）

作者：Dan Donathan

## 可以构建的内容（What You Can Build）
代码重构工具：开发一个智能代码重构工具，遵循 .cursorrules 文件中列出的原则。该工具可自动检测代码坏味道（code smells），建议简化代码的改进方案，并确保应用 DRY、KISS 和童子军规则（Boy-Scout Rule）等最佳实践。单元测试生成器：创建一个为 Angular 组件自动生成单元测试的工具，确保所有新代码在合并前得到充分测试。该工具应分析现有代码并创建覆盖广泛边缘情况的测试。实时代码审查系统：构建一个在编写代码时提供实时反馈的平台，指出可以应用 YAGNI、Curly 定律和最小惊讶原则（Principle of Least Astonishment）等原则来提升代码质量的地方。Angular 组件分析器：开发一项服务，分析独立（standalone）Angular 组件并就其与 Novo Elements 的集成提供洞见。它应检查最佳实践、兼容性问题和优化机会。代码维护仪表板：构建一个跟踪代码库可维护性的仪表板。它应使用度量指标评估代码整洁度、对 DRY 和 Curly 定律等规则的遵守情况，并给出改进建议，让代码维护更轻松。项目结构优化器：设计一个为使用 Novo Elements 的 Angular 项目建议最优文件和目录结构的工具，确保项目保持清晰、有条理、无冗余。自动化文档生成器：开发一个为 Angular 项目创建全面易懂文档的生成器，重点阐明代码功能和预期行为，以遵循最小惊讶原则。调试助手：创建一个 AI 驱动的调试助手，通过生成详细日志和提供可能的修复方案来帮助识别和解决问题，基于 .cursorrules 中的调试和测试规则。代码质量检查器：实现一项服务，实时依据所提供的风格和格式化指南检查代码，确保一致的命名约定并使用最新版本的库。过早优化检测器：开发一个分析代码中不必要优化的工具，并建议开发者何时应关注关键效率，契合"过早优化是万恶之源"的理念。

## 简介（Synopsis）
本 prompt 对使用独立组件和 Novo Elements 的 Angular 开发者很有用，提供指南以确保高效、可维护的代码并遵循现代最佳实践。

## .cursorrules prompt 概述（Overview of .cursorrules prompt）
.cursorrules 文件概述了一套编码标准和原则，指导开发者创建最优的、可投产的代码。它强调保留现有代码结构、验证更改并交付简洁的解决方案。重点介绍了 DRY（Don't Repeat Yourself）、KISS（Keep It Simple Stupid）和 YAGNI（You Aren't Gonna Need It）等关键编码原则，以保持代码质量、避免不必要的复杂性。它还包括调试、测试和维护项目结构的具体规则，以及将 Angular 与独立组件和 Novo Elements 集成。该文件旨在通过充分的测试、清晰的文档和最小化的代码更改 diff，高效地满足指定的项目需求。
