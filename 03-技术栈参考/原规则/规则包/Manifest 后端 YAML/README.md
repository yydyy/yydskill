# Manifest 后端 .manifestrules 提示

## 🚀 你可以构建什么

功能完备的后端，包含数据、存储与逻辑——涵盖认证、自定义钩子乃至管理面板等必备功能。这些后端可服务于各类应用：

- **博客 API：** 用富文本、日期与选择类型字段管理文章、作者与评论。

- **无头 CMS 后端：** 提供 API 优先的内容管理系统，含内容类型、条目与本地化支持，服务于解耦的前端。

- **联系表单服务：** 以最少配置和公开创建策略收集并列出公开咨询。

- **产品目录：** 存储带图片、价格与分类的产品；演示选择属性与关系。

- **活动排期器：** 使用日期、数字与选择类型处理活动、参与者与 RSVP。

- **待办清单应用：** 以公开读取策略追踪任务、状态与优先级。

- **用户资料：** 无需认证即可保存资料信息、头像与设置。

- **分析日志记录器：** 收集带时间戳与元数据的事件日志，用于演示仪表板。

- **反馈收集器：** 带创建与读取策略的公开评论服务。

- **文件元数据存储：** 演示文件上传与元数据追踪（文件名、大小、类型）。

- **交互式编码演练场：** 一个后端，为 AI 驱动的编程导师存储练习、提示与用户提交内容。

- **功能开关管理后端：** 管理功能开关、发布日期与用户分组分配。

- **问卷引擎后端：** 用选择与数字类型定义问卷、问题与回答。

## ✨ 优势

**无缝的 AI 集成：** Manifest 基于规则的 schema 让 LLM 无需手动喂入 schema 即可生成有效的后端代码。
**错误预防：** 自动的 schema 与格式校验及早发现问题，节省调试时间。

**Token 高效：** 在提示 AI 助手时内嵌 Manifest 的约定，可减少 token 消耗。

**快速原型：** 几分钟内搭建起带数据存储与逻辑的完整可用后端。

**顺畅的开发体验：** 留在你的编辑器里，不间断地编码或 vibe-code 你的应用。

## 📋 简介

本提示文件指导使用 Manifest 生成后端。它内嵌了你在文件结构、带属性类型的实体生成、关系与策略方面的规则。用它驱动你的 LLM 产出简洁、有效的 manifest/backend.yml 文件。
