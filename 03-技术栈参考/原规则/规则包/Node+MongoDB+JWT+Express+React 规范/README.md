## 你可以构建什么
竞猜池管理平台：一款允许用户浏览可用竞猜池、提交请求并管理参赛条目的 Web 应用。它包括一个用于管理竞猜池请求、付款和条目的管理面板。该平台确保用户可以查看竞猜池排名并跟踪每个条目的选择。先选后付系统：一项在线服务，让用户提交竞猜池请求并安全完成付款。系统会跟踪每个请求的付款状态，并在管理员批准后转入条目创建。请求审批仪表盘：一个面向管理员的仪表盘，提供工具来审核、批准或拒绝用户提交的参赛条目请求。它集成了付款状态跟踪和请求从待处理到已批准的进度跟踪。条目与计分系统：一个后端解决方案，处理批准后的条目创建，管理每个条目的用户选择，并在比赛结束后自动计分以更新排名并淘汰排名靠后的条目。用户排名展示：一项呈现详细竞猜池排名的服务，显示所有用户条目的排名，并允许用户在比赛计分后查看自己的选择和分数。请求与条目限制模块：一个后端功能，对每个用户在每个竞猜池中的请求和条目数量强制执行限制，确保符合系统关于允许的请求和条目数量的规则。选择截止时间管理工具：一个允许用户在设定的截止时间（如比赛开始时间或每周特定截止点）之前做出或更新选择的系统，确保公平竞争和及时提交。伪代码策略规划器：一个规划辅助工具，帮助开发者在实现之前用伪代码勾勒 API 端点和业务逻辑，增强策略规划并确保开发符合用户需求。付款状态集成：Request 模型中的一项功能，跟踪并更新付款状态，确保只有在付款完成和管理员批准后才创建条目。安全认证服务：一个基于 JWT 的认证系统，确保用户和管理员的安全访问控制，保护用户请求和竞猜池数据等敏感信息。

## 概要
开发者可以使用此提示词构建基于竞猜池的游戏应用，包含用户提交、支付处理和管理员审批工作流，利用 Node.js、MongoDB 和 React.js 高效管理用户和条目。

## .cursorrules 提示词概览
该 .cursorrules 文件为一个软件项目提供了全面的蓝图，涉及后端与 Node.js 和 Express.js 的集成，以及可能使用 React.js 的前端。它使用 MongoDB 配合 Mongoose 进行数据库管理，并采用 JSON Web Tokens 进行认证。建议使用 Git 进行版本控制，Docker 可选用于部署。文件强调精确遵循用户需求，尤其是遵守游戏规则和用户流程，并建议在实现功能前先编写详细的伪代码。它概述了用户在应用中的旅程，从浏览竞猜池到提交请求、处理付款和管理条目。它描述了管理请求、创建条目和管理选择的结构化流程，同时通过安全高效的实践保持代码质量。最后，它为实现状态转换以及跟踪请求、条目和付款状态等要素提供指导。
