# PR 模板指南（PR Template Prompt）

一个专门用于创建标准化 Pull Request 模板的 .cursorrules 提示词，以改善代码评审流程和团队协作。

## 你可以构建什么

- **GitHub PR 模板**：面向 GitHub Pull Requests 的结构化模板
- **GitLab MR 模板**：面向 GitLab Merge Requests 的格式化模板
- **Azure DevOps PR 模板**：为 Azure DevOps Pull Requests 量身定制的模板
- **自定义平台模板**：适用于其他版本控制平台的可调整模板
- **项目专属模板**：针对特定项目需求和工作流量身定制的模板

## 优势

- **标准化提交**：所有代码变更提交采用一致的格式
- **改进评审流程**：清晰的结构，便于高效代码评审
- **跨团队理解**：技术和非技术团队成员都能理解的模板
- **信息完整**：确保每次 PR 都提供所有必要细节
- **减少来回沟通**：最大限度减少评审者要求补充信息的情况
- **多平台支持**：适用于不同版本控制系统的模板

## 简介

这一提示词帮助技术写作者和开发者创建标准化的 PR 模板，通过确保所有 PR 包含关于变更内容、目的、已做测试和潜在影响的必要信息来改善代码评审流程。

## .cursorrules 提示文件概述

`.cursorrules` 提示词指导用户创建有效的 PR 模板，包含以下关键要素：

- **格式支持**：面向 GitHub、GitLab 和 Azure DevOps 的 Markdown 模板
- **最佳实践**：创建清晰有效 PR 模板的八条基本实践
- **示例模板**：针对不同平台和用例的详细示例
- **定制指导**：将模板调整为特定项目需求的建议
- **章节指南**：PR 模板必备章节的建议
- **评审检查清单**：确保彻底代码评审的检查清单示例
