## 你可以构建什么
代码质量分析工具：一个分析 TypeScript 代码是否遵循预定义约定（如函数声明偏好、命名约定以及优先使用 interface 而非 type）的在线平台。它提供详细的反馈和改进建议。Next.js 优化平台：一个帮助优化 Next.js 应用的工具，聚焦服务端组件、懒加载，以及尽量减少客户端副作用的使用。该平台可以提供可行的见解和性能改进建议。响应式设计助手：一个与 Tailwind CSS 集成的 Web 应用，帮助开发者创建响应式 UI。它提供符合移动优先设计原则的模板和风格指南，使用 Radix UI 和 Shaden VI 组件。Supabase 架构构建器：一个用于在 Supabase 中创建和管理数据库架构的图形用户界面工具。它可视化数据库中的结构和关系，让开发者更轻松地构建数据模型。TypeScript 接口生成器：一个从 JSON 对象或数据库架构自动生成 TypeScript 接口的应用，强调使用 interface 而非 type，并避免使用 enum。Web 性能追踪器：一项监控应用 Web Vitals（LCP、CLS、FID）指标并提供分析的服务，给出改善加载时间、渲染和用户交互指标的具体策略。React 组件 Suspense 包装器：一个组件库，帮助开发者轻松地用 Suspense 包装 React 组件，提供可定制的加载状态和回退内容。动态组件加载器：一个 next.js 插件，通过根据用户交互或其他触发条件动态加载非关键组件来优化应用性能，减少初始加载时间。图片优化服务：一个基于 Web 的实用工具，将图片转换为 WebP 格式、包含尺寸数据并实现懒加载，以便集成到 Web 项目中，提升页面加载性能。状态管理助手：一个使用 hooks 管理搜索参数和状态的工具，符合限制客户端数据获取和状态管理的关键约定，遵循 Next.js 和服务端渲染的原则。

## 概要
使用 TypeScript、React 和 Next.js 构建现代 Web 应用的开发者将受益于建立清晰、简洁的编码标准和优化实践，从而提升应用的性能和可维护性。

## .cursorrules 提示词概览
该 .cursorrules 文件概述了使用 TypeScript、Node.js、Next.js、React 以及 Radix UI 和 Tailwind CSS 等相关工具开发应用的最佳实践和约定。它强调使用函数式编程模式编写简洁、技术性的 TypeScript 代码，同时避免使用类和代码重复。文件建议了命名约定，如目录使用小写加连字符，并优先使用 interface 而非 type 和 enum。文件还详述了性能优化策略，包括最小化客户端状态以及使用 React Server Components 和动态加载。对于数据库交互，它推荐使用 Supabase 进行数据获取和架构管理。此外，它还提供了关于响应式设计、利用 Tailwind CSS 以及优化 Web Vitals 的指导。
