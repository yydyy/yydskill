作者：Malcolm Jones (bossjones/Tony Dark)

## 你可以构建什么
交互式编程助手：开发一款根据用户输入提供实时反馈和编码建议的工具。它运用沟通技巧提出澄清性问题，并按用户的专业水平调整回复。
协作式代码评审平台：一个平台，开发者可在其中分享代码并获得关于最佳实践、改进和重构建议的反馈。该工具有助于分解复杂问题，并通过测试指导验证方案。
代码质量检查器：一款分析代码错误、性能问题以及是否遵循 SOLID 原则等最佳实践的应用。它提供错误处理、日志记录和文档方面的建议。
声明式范式模拟器：一款把命令式代码片段转换为声明式或函数式风格的工具，展示不可变性和可组合性的优势。
领域特定语言（DSL）创建器：一款帮助领域专家和利益相关者为其领域定义和创建元语言抽象的应用，让代码库获得更好的语义命名和清晰度。
可复用组件库：一项识别并汇总跨项目常见模式和模型的服务，提供可复用组件和服务库。
技术沟通平台：一项根据用户专业水平调整技术细节深度和语气的服务，使用 markdown、项目符号列表或表格提供简洁、结构化的回复。
限制记录器：一款帮助开发者在代码库中清晰陈述假设和限制的工具，为未来参考和开发留下记录。
代码重构建议引擎：一款智能工具，提出代码重构的修改建议，保持编码风格约定，并在需要时提供替代方案。
运维指导系统：一个平台，为开发过程每个步骤的测试和验证提供操作说明，确保方案完整并有效处理边界情况。

## 简介
希望构建协作式问题解决工具、代码质量分析器或编程指导平台的开发者，可以通过落实有效沟通、编程范式和代码清晰度方面的标准而获益。

## .cursorrules 提示文件概述
`.cursorrules` 文件为开发者提供了一个框架，用于提升软件开发项目中的沟通、问题解决和代码质量。它强调澄清用户需求、通过协作对话提出方案，以及把复杂问题分解为可管理步骤的重要性。文件鼓励采用编码最佳实践，如遵循 DRY 和 SOLID 原则、错误处理和保持代码一致性。它倡导声明式和函数式编程范式，同时保持模块化和可维护的代码。文件突出使用语义化命名、定义清晰的抽象和平台化思维来提升清晰度与复用性。此外，`.cursorrules` 文件还制定了回复格式、处理不确定性，以及使用 `pyproject.toml` 中所列当前架构选择的指南。它提供了一种结构化的软件开发方法，促进高效沟通和彻底的问题解决。
