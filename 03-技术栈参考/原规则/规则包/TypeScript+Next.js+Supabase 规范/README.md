## .cursorrules 提示词概览
`.cursorrules` 文件为使用 TypeScript、Next.js、React 及相关库（如 Shadcn UI、Radix UI、Supabase、Tailwind 和 Vercel AI SDK）开发项目提供指导方针。它强调使用函数式编程原则编写简洁、模块化的 TypeScript 代码。文件概述了命名、语法、UI 样式和性能优化方面的具体约定。它建议使用 Supabase 进行数据库操作，并详述了与 Vercel AI SDK 的集成以实现 AI 功能。文件还就高效数据获取、错误处理、SEO 优化给出指令，并要求遵循 Next.js 文档中关于路由、渲染和数据获取的最佳实践。目标是在项目中保持高性能、可读性和可维护性。
