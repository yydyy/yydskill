## Open Code Review（ocr）

- **是什么**：Agent skill（名字 `ocr`，v2.5.0，Apache-2.0）。以「Tech Lead 协调多个 reviewer 角色」的方式做代码评审：安全、架构、测试、性能等视角各出一份意见再汇总。支持评审 commit / 分支 / PR，带 `ocr dashboard` 看板。
- **装在哪**：
  - skill 正文：`D:\Documents\cocosTemplate\.agents\skills\ocr\SKILL.md`（项目级，cocosTemplate）。曾装在用户级 `~/.agents/skills/ocr`，现以项目内这份为准。
  - CLI：npm 全局包 `@open-code-review/cli` v2.5.0，入口 `D:\Programs\nodejs\ocr.ps1`（`ocr --version` 可验证）。
  - 配套：项目里 `ocr init` 会生成 `.ocr/`（config.yaml、commands、session）；`.ocr/skills` 是指向 `.agents/skills/ocr` 的目录联接（Junction），换机需重建。
- **怎么用**：对 Agent 说「review my code / 检查这个 PR」即触发；完整工作流前需在目标项目执行一次 `ocr init`（`ocr doctor` 自检）。
- **依赖**：git 必需；gh CLI 可选（GitHub 集成）。

## codeGraph

- **是什么**：MCP server。把仓库索引成「代码图谱」，暴露符号定义、调用与依赖关系查询，让 Agent 不用全文搜索就能定位代码结构。启动命令 `npx -y @colbymchenry/codegraph serve --mcp`。
- **装在哪**：`C:\Users\yyd\.kimi\mcp.json`（Kimi 客户端）注册为 `codegraph`；本机索引/守护进程数据在 `C:\Users\yyd\.codegraph\`（daemons、telemetry）。
- **备注**：属于按项目建索引的工具；若某项目查询不到结果，先在该项目跑一次索引构建。

## code-review-graph

- **是什么**：Python MCP server（`uvx code-review-graph serve`），提供图谱化的代码评审分析工具集。
- **装在哪**：`C:\Users\yyd\.qoder\mcp.json`（Qoder 客户端）注册为 `code-review-graph`，工作目录 `C:\Users\yyd`。
- **备注**：与 Open Code Review 的分工——`ocr` 是多角色评审流程（skill），code-review-graph 是结构化分析能力（MCP）。

## mcp-bridge

- **是什么**：自研 MCP server（Node），为 Cocos Creator 2.4.x 编辑器做桥接：场景/节点增删改、组件管理、脚本读写、资源（场景/预制体/材质/纹理）管理、离线改 `.prefab`/`.fire`、批处理与实时日志。
- **装在哪**：入口 `D:\Documents\mcp-bridge\dist\mcp-proxy.js`；注册在 `C:\Users\yyd\.trae-cn\mcp.json`（Trae）与 `C:\Users\yyd\.gemini\mcp.json`（Gemini），命令 `node D:/Documents/mcp-bridge/dist/mcp-proxy.js`。
- **备注**：代码在 `D:\Documents\mcp-bridge`（含 README、UPDATE_LOG）；只适配 Cocos Creator 2.4.x。

## security-audit-skill（安全审计）

- **是什么**：Agent skill（名字 `security-audit`），做 **PHP 代码安全审计**：按 OWASP 模式识别漏洞（注入、鉴权、敏感信息泄露等），输出发现与修复建议。兼容 Claude Code 等 Agent Skills 环境。
- **来源**：[netresearch/security-audit-skill](https://github.com/netresearch/security-audit-skill)（Netresearch，另有 [skills.sh 上架页](https://www.skills.sh/netresearch/security-audit-skill/security-audit)、[Netresearch Skills Marketplace](https://netresearch.github.io/claude-code-marketplace/en/skills/security-audit/)）。
- **安装方式**（任一）：`npx skills add netresearch/security-audit-skill`，或按 skills.sh / marketplace 页的安装命令装到 Agent 的 skill 目录。
- **状态**：截至 2026-09-26，本机（`~/.agents/skills`、`~/.cursor/skills`、各 Agent 配置目录）**未检索到已安装副本**，先登记来源，用到时再装。
- **相关**：同一作者还有 Packagist 包 `netresearch/agent-audit`/`agent-security-audit`（Composer 生态的 agent 安全审计工具），如做 PHP 项目可一并评估。
- **与 Cursor 内置 `review-security` 的区别**：`review-security` 是 Cursor 官方内置的「安全评审子代理」入口；security-audit-skill 是第三方 PHP 专项审计 skill，深度更深、可跨 Agent 用。
